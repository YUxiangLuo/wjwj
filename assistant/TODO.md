# Teacher 端待完成功能

## 课题创建向导（6步）

位置：`/topics/create`

根据 UI 规格，需要实现多步骤向导：

1. **Step 1: 基本信息**
   - 课题名称（必填，最多200字）
   - 背景描述（必填，富文本编辑器，最多5000字）

2. **Step 2: 上传数据**
   - 文件上传区域（仅支持 xlsx/xls，最大100MB）
   - 上传后预览表格
   - 显示行数统计
   - 文件格式错误提示

3. **Step 3: 字段映射**
   - 显示所有 Excel 列
   - 每列可选择包含/排除
   - 字段类型下拉选择：
     - 分层变量（用于分层抽样）
     - 数值变量（用于均值比较）
     - 分类变量（用于比例比较）
     - 标识符（排除分析）
   - 验证：至少3个字段，1个分层变量，1个数值变量

4. **Step 4: 附件上传（可选）**
   - 多文件上传
   - 支持：图片、视频、文档
   - 文件列表带删除按钮

5. **Step 5: 推荐问题（可选）**
   - 问题列表
   - 添加问题按钮
   - 问题类型：判断题、单选题、多选题、量表题

6. **Step 6: 评分权重**
   - 三个滑块/输入框：
     - 问卷设计权重：___%
     - 实验过程权重：___%
     - 报告撰写权重：___%
   - 验证：总和必须等于100%
   - 按钮："保存为草稿"、"保存并发布"

## 批改详情页面

位置：`/grading/:submissionId`

根据 UI 规格，需要实现左右分栏布局：

### 左侧：学生提交内容
- Tab 切换：[问卷] [报告]
- PDF 预览区域
- 缩放控制：[-] [100%] [+]
- 页码导航：[1] of 5
- 下载 PDF 按钮

### 右侧：批改面板
- 学生信息：姓名、学号
- 分项评分：
  - 问卷设计：机器评分显示 + 教师评分输入 (0-100)
  - 实验过程：教师评分输入 (0-100)
  - 报告撰写：教师评分输入 (0-100)
- 总分计算：显示加权公式和结果
- 评语输入框
- 操作按钮：
  - [保存草稿] - 保存但不提交，学生看到"待批改"
  - [驳回] - 打开驳回弹窗，输入驳回原因
  - [通过] - 完成批改
  - [下一个 →] - 保存并跳转下一个待批改

### 驳回弹窗
- 标题："驳回作业"
- 提示："请输入驳回原因，供学生改进："
- 文本框：必填，最多500字
- 按钮：[取消] [确认驳回]
