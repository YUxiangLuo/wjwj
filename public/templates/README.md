# 数据上传模板说明

本目录包含数据上传的模板文件和示例，供教师在创建课题时参考使用。

## 文件清单

| 文件名 | 说明 | 用途 |
|--------|------|------|
| `空白模板.csv` | 标准空白模板 | 直接下载使用，替换为自己的数据 |
| `数据上传说明.md` | 详细使用文档 | 了解数据格式要求和配置方法 |
| `消费者行为调查_示例.csv` | 消费者调查示例 | 参考数据结构和字段类型设置 |
| `大学生网购趋势_示例.csv` | 网购调查示例 | 适合市场调研类课题 |
| `市场调研基础_示例.csv` | 基础调研示例 | 适合基础统计教学 |

## 快速开始

### 1. 下载模板
点击 [空白模板.csv](./空白模板.csv) 下载标准模板。

### 2. 准备数据
按照以下结构准备数据：

```
必需字段类型：
├── 标识符字段（1个）：如 id、编号（唯一标识每条记录）
├── 分层变量（1-3个）：如性别、年级、地区（分类数据，类别≤20个）
└── 数值变量（1个或多个）：如年龄、收入、分数
```

### 3. 字段映射配置示例

上传数据后，在系统中配置字段映射：

**示例1 - 消费者行为调查：**
- 标识符：`id`
- 分层变量：`gender`, `education`, `province`
- 数值变量：`age`, `income`, `satisfaction`

**示例2 - 大学生网购趋势：**
- 标识符：`student_id`
- 分层变量：`grade`, `major_category`, `platform_preference`
- 数值变量：`monthly_spending`, `purchase_frequency`

## 数据格式规范

### 基本要求
- **文件格式**：Excel (.xlsx, .xls) 或 CSV
- **数据行数**：1 - 100,000 行
- **数据列数**：2 - 50 列
- **表头**：第一行必须是表头，列名不能重复

### 分层变量要求
- 必须是**分类数据**（如男/女、本科/硕士）
- **类别数量 ≤ 20**
- 常见分层变量：性别、年龄段、学历、地区、职业类别

### 数值变量要求
- 必须是**数值型数据**
- 可用于统计计算的字段
- 常见数值变量：年龄、收入、消费金额、评分

## 常见问题

**Q: 系统提示"分层变量唯一值超过20个"**
> 将连续型数据转换为分类数据。例如：将具体年龄（18,19,20...）转换为年龄段（18-25, 26-35...）

**Q: 可以上传CSV文件吗？**
> 可以，系统支持 .xlsx、.xls 和 .csv 格式

**Q: 数据需要清洗吗？**
> 建议上传前清洗数据，删除空行、处理异常值
