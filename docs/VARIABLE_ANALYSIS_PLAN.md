# 变量字典、问卷关联与自主分析开发计划

状态：主分支后续开发计划，尚未实施。各阶段独立实现、验收和合并。

本计划提取 `feat/questionnaire-variable-analysis` 的核心产品能力，在 `main` 上重新设计和实现；不合并该分支，也不要求复刻其提交顺序、接口或组件结构。本文描述目标行为，不代表当前产品已支持这些功能。当前规则以[教学指南](TEACHING.md)和[课题模型](../RESEARCH_MODEL.md)为准。

## 目标与范围

在现有四阶段教学流程之上，增加五项可选能力：

1. 教师确认总体变量字典。
2. 学生使用数值题，并将题目关联到真实变量。
3. 学生对实际样本执行单变量自主分析，独立保存结果。
4. 将分析引用到报告，并在提交时冻结相关材料。
5. 导出包含样本、变量说明和来源信息的 XLSX 码本。

题目关联和自主分析是两条独立路径，都依赖变量字典；学生不必先关联问卷，才能分析真实变量。报告引用依赖已保存的分析，完整码本整合字典、题目关联及抽样来源。

### 共同约束

- 问卷继续用于认知预试，试填答案不参与统计，不生成总体中不存在的数据列，也不表示既有总体数据由本问卷采集。
- 新能力初期全部可选，不增加必做门槛，不改变原有主要研究目标、阶段完成规则或评分权重。
- 历史任务、报告和成绩继续可读；未使用新功能的实验仍按原流程完成。
- 本期不做回归、交叉表、分组分析、多选联合描述或新的统计推断体系。
- 不将旧格式清理、CSV 解码收紧、全项目 JSONB 兼容逻辑删除纳入本次功能开发。

## 阶段 1：教师变量字典

### 交付

- 为总体字段定义显示名称、单位、测量类型、类别原值与标签、类别顺序及缺失编码。
- 提供建议、编辑、明确确认保存和只读查看；建议不自动视为已确认配置。
- 保存数据来源标识和字典修订号，校验完整总体；旧页面不能覆盖新配置。
- 已发布或已分配任务的模板冻结字典，修改须复制模板。替换总体或改变字段解释时使字典失效；等价保存不使其失效。

### 验收

- 文本 `"01"`、文本 `"1"` 和数值 `1` 不混为同一编码；`0` 和 `false` 不自动视为缺失。
- 分类字典覆盖完整总体的有效类别，不只检查预览行；数字外观不自动表示连续变量。
- 确认、换源、复制、发布和分配任务之间的并发不会造成过期覆盖或绕过冻结。
- 保存失败保留输入；来源或版本冲突要求明确重新加载核对。
- 旧模板没有字典时仍可正常使用，不自动补造历史定义。

## 阶段 2：数值题与题目—变量关联

### 交付

- 增加数值题，支持单位、含边界的上下限及小数位限制；输入有效后明确继续试填。
- 单选和是/否题对应一个分类字段，评分题对应有序类别，多选题的每个选项对应不同的真实二值字段，数值题对应连续变量。
- 关联记录任务范围、字典修订及题目语义。确认关联只改变问卷草稿，随原阶段保存流程持久化。
- 题意或规则改变时清除原关联并提示核对；复制题目不继承关联，单纯调整题目顺序保留关联。

### 验收

- 数值题明确校验边界和小数位，不把空值当零、不静默舍入或换算单位。
- 数值题的单位与变量定义一致；试填限制不筛选、截断或改写总体数据。
- 单值选项与全部有效类别一一对应；多选不能用一列普通分类字段伪装多个响应列。
- 保存和最终提交检查关联归属、来源和题目语义；失效关联不能静默更新版本。
- 无关联问卷仍按原流程完成。为稳定选项身份确需调整存储时，另行设计兼容迁移，不顺带收紧历史问卷提交规则。

## 阶段 3：单变量自主分析

分两次交付：先实现未加权描述及结果保存，再加入经过独立验证的设计加权点估计。

### 交付

- 阶段 4 增加自主分析工作区，明确填写研究问题，选择一种实际完成的样本、一个已确认变量和分析口径。
- 连续变量提供有效数、缺失数、均值、样本标准差、极值和分位数；分类变量提供频数和有效比例，保持字典类别顺序。
- 设计加权版本提供均值和类别比例的比率点估计；权重来自实际抽样设计，不由浏览器指定。
- 配置改变不自动运行。每次成功生成独立保存记录，包含配置、变量定义、结果、算法版本及来源证据；不覆盖已有结果。
- 耗时计算放入有界 Worker，设置并发、排队、超时和记录容量限制，具体数值在本阶段确定。

### 验收

- 服务器从原总体和实际抽样记录恢复样本，并核验来源、索引和抽样设计；不采用浏览器上传的数据、权重或计算结果。
- 明确区分样本标准差与标准误；分位数算法固定并注明。无有效值或仅一个有效值时，不可用统计量不以零替代。
- 权重验证覆盖简单随机、系统、分层和 PPS；不将原始频数显示成加权人数。
- 设计加权口径遇到总体分析字段缺失时明确拒绝，允许改做原始描述；不隐式填补缺失或校正权重。
- 不提供加权分位数、通用标准误、置信区间或显著性检验，不宣称比率点估计无偏。
- 数值溢出或尺度不可靠时明确报错，不返回 NaN、Infinity 或静默改单位。
- 相同请求重试不重复保存；同一请求身份不能用于不同配置。写入前重新检查实验版本、状态、归属、来源和容量。

## 阶段 4：报告引用与提交冻结

### 交付

- 从已保存分析中选择报告附录；选择和移除先作用于草稿，随正常保存报告生效。
- 提交时冻结所选结果、变量定义、配置及来源信息；学生和教师读取同一份提交材料。
- 抽样成果使用独立的单调代次标识，区分重复使用同一种子产生的不同轮次。
- 重做上游阶段沿用原有下游重置规则，清除报告引用但保留历史分析记录，并标为过期。

### 验收

- 保存报告和最终提交都检查引用归属及来源；过期引用需重新运行、替换或明确移除。
- 重做抽样不能使旧分析重新变为有效，仅编辑正文不使分析失效。
- 附录不替代学生正文、不计入正文最低字数，不自动生成解释或改变评分权重。
- 历史提交不补入当前字典或分析表中的结果；未选择分析仍可正常提交。

## 阶段 5：XLSX 样本与码本导出

### 交付

- 保留现有 CSV 入口，新增 XLSX 导出，包含完整原始样本、变量说明、精确编码、缺失规则、题目关联、抽样设计和逐行设计权重。
- 原始样本与说明信息放在独立工作表，不将试填答案或虚构变量写入样本。
- 未提交时使用已保存版本；提交后依据冻结信息核验来源并恢复样本，不读取浏览器草稿。
- 导出使用有界 Worker，限制单元格数、文本容量、排队量及执行时间。

### 验收

- 导出完整实际样本，不采用页面预览的截断数据。
- 保留原始字段、编号、前导零及原值类型；文本按文本单元格写入，不执行公式。
- 缺失编码保持原值；设计权重不冒充缺失校正，也不表示已支持回归或推断。
- 缺少字典或来源不匹配时明确拒绝新导出能力，不用当前模板补齐历史来源；无字典时仍可使用原有 CSV。
- 超限明确报错，支持选择更小导出范围，不静默截断内容。

## 实现与迁移原则

- 每阶段在 `main` 的现有模块、服务和组件模式上实现，采用交付完整行为所需的最小变更。
- 接口命名、组件划分、JSON 结构和容量数字不沿用参考分支作为既定约束，在阶段实施前确定。
- 功能实现与兼容性清理分开。仅对新功能必需的存储变更设计显式增量迁移，不通过迁移重新解释历史成绩或题意。
- 数据库变更先在独立恢复库演练，确认数据库和 `storage/` 的配套备份与恢复路径；不使用 reset 掩盖升级问题。
- 实施完成后将当前规则更新到对应专题文档，并更新本计划的阶段状态；不把计划当作已上线功能说明。

## 验证与推进顺序

每阶段独立验收后再合并，不将全部能力积累成一个大分支：

1. 领域测试：编码类型、缺失值、边界值、来源失效及统计结果正确性。
2. 持久化测试：涉及数据库时使用独立测试库，覆盖迁移、归属、并发、冻结和幂等。
3. 浏览器验收：覆盖成功、失败、版本冲突及恢复流程；涉及外观时检查实际渲染结果。
4. 兼容性回归：无字典旧模板、进行中的旧问卷、已完成规划、已提交报告、已评分实验及现有 CSV 导出。

优先启动阶段 1。它既是后续能力的共同基础，也可独立改善教师对字段含义和编码的管理。阶段 3 的设计加权分析必须在未加权描述和样本来源验证稳定后交付。
