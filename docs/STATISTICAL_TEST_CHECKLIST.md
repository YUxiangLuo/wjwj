# 统计学专业验收清单

本文供具有抽样调查或统计学背景的测试者验收统计口径。重点是证明**目标定义、样本量规划、抽样设计、估计量、设计标准误和解释文字彼此一致**，而不是只检查页面能否完成操作。

产品边界以[课题模型](../RESEARCH_MODEL.md)为准：当前主流程只支持已有完整有限总体表，以一个数值均值或一个明确类别比例为单一主要目标的描述性抽样教学。问卷只用于认知预试，不产生估计数据。功能与并发、安全、文件测试另见[高风险测试检查清单](TESTER_RISK_CHECKLIST.md)。

## 1. 验收原则

### 优先级

| 级别 | 统计影响 | 发布要求 |
| --- | --- | --- |
| S0 | 目标、样本、权重、估计量或标准误错误，足以改变统计结论 | 必须全部通过 |
| S1 | 边界数据不可恢复、警示缺失、数值精度或复现性错误 | 必须通过，或书面接受风险 |
| S2 | 辅助图表、格式、教学措辞不准确但不改变底层数值 | 记录并排期 |

### 独立性要求

- [ ] 期望值必须手算、枚举全部可能样本，或由与项目实现独立的软件计算；不能调用被测函数生成自己的期望。
- [ ] 计数、样本索引、类别编码、种子和整数分配精确比较；浮点数建议使用 `|实际−期望| ≤ 1e-12 + 1e-12×|期望|`，极端尺度另设有推导依据的容差。
- [ ] 每个结论同时核对 UI、导出和 API/数据库冻结值，不能只看四舍五入后的页面文本。
- [ ] 随机抽样先验证每次抽取的不变量，再验证跨重复抽样的设计分布；不能用一次“看起来随机”的样本判定正确。
- [ ] 记录总体顺序、完整原始值类型、映射、字典、随机种子、抽样代次和算法版本，使反例可复现。

## 2. 当前公式与口径

测试者应先确认产品仍采用本节口径；如产品规则改变，应先修改事实来源和基准，不能通过放宽断言迁就实现。

### 2.1 样本量规划

比例目标把误差限 `E` 解释为比例尺度，例如 5 个百分点为 0.05：

```text
n₀ = z² p(1−p) / E²
```

默认 `p=0.5`，这是在其他条件相同时使 `p(1−p)` 最大的保守规划值。均值目标使用与均值相同单位的绝对误差限 `e`，总体方差采用分母 N 的 `σ²`：

```text
n₀ = z² σ² / e²
```

两类目标之后执行同一顺序：

```text
n_deff = n₀ × deff
n_fpc  = n_deff × N / (N − 1 + n_deff)
n_invite = ceil(n_fpc / (1 − r))，并封顶为 N
```

其中 `r` 是预期无回答率。中间展示值可以分别向上取整，但下一步必须继续使用未取整的原始值。预期完成量为 `n_invite×(1−r)`，允许是小数；邀请数为整数。

有限总体方差因子采用：

```text
(N−n)/(N−1)
```

总体统计通常保存分母 `N−1` 的 `S²`，规划前须转换为 `σ²=S²(N−1)/N`。这是历史上最容易发生口径错位的位置。

### 2.2 点估计与设计标准误

| 设计 | 点估计 | 当前标准误口径 |
| --- | --- | --- |
| 简单随机不放回 | 样本均值；比例视为 0/1 均值 | `SE=sqrt((1−n/N)S²/n)`；普查为 0 |
| 线性系统抽样 | 样本均值 | 对 `r∼Uniform[0,K)` 的全部随机起点区间精确积分，不用 SRS SE 替代 |
| 分层随机抽样 | `Σ W_h ȳ_h`，`W_h=N_h/N` | `SE²=Σ W_h²(1−n_h/N_h)S_h²/n_h` |
| 不放回 πps | Hájek 比估计 `Σ(y_i/π_i)/Σ(1/π_i)` | 对固定 π 系统设计的随机起点精确积分；普查为 0；精度不足时返回不可用 |

比例目标通过 0/1 指示变量使用同一套设计公式。PPS 的 `π_i` 是纳入概率，不是单次抽取概率；必入单位满足 `π_i=1`、设计权重 `1/π_i=1`，且所有纳入概率之和应为样本量。

“等效 SRS 样本量”由同一有限总体上的设计 SE 反解：

```text
n_eff = S² / (SE² + S²/N)
```

它是信息量对照，不是实际入样量，也不能单独证明正态近似成立。

### 2.3 单变量描述

- 未加权连续变量：有效值均值、分母 `n−1` 的样本标准差、最小值/最大值、R type 7 四分位数。
- 未加权分类变量：按字典编码分别计数，比例分母为有效值数；字典中的零频类别仍须出现。
- 设计加权结果：只提供连续变量加权均值或分类变量加权比例的点估计；原始频数不能标成加权人数。
- 当前不提供加权标准差、加权分位数、加权标准误或加权置信区间；对应位置必须为空或明确说明未提供。
- 加权分析要求总体目标字段完整；不能只删除样本中的缺失值后假装权重仍对应完整总体。

## 3. 独立数值基准

以下夹具专门选择非对称值，使常见的错误公式无法侥幸通过。

### ST-B1：比例样本量

参数：`N=1000, z=1.96, p=0.5, E=0.05, deff=1, r=0`。

```text
n₀ = 384.16
n_fpc = 277.740...
n_invite = 278
```

- [ ] 页面四步法、服务端保存值和最终抽样规划量均为 278。

### ST-B2：设计效应与无回答顺序

参数同 ST-B1，但 `deff=1.5, r=0.2`。

```text
n_deff = 576.24
n_fpc = 365.8109240496686
n_fpc/(1−r) = 457.2636550620857
n_invite = 458
expectedCompleted = 366.4
```

- [ ] 任何“先做 FPC 再乘 deff”、逐步用已取整值继续计算或把 366.4 显示成邀请数的实现都应失败。

### ST-B3：均值样本量与方差口径

参数：`N=1000, z=1.96, σ²=100, e=2, deff=1, r=0`。

```text
n₀ = 96.04
n_fpc = 87.70455873758036
n_invite = 88
```

- [ ] 若原始总体统计给出 `S²`，先按 `σ²=S²×999/1000` 转换；不能把 `S²` 原样代入规划。

### ST-B4：描述统计与 R7 分位数

样本：`[0, 2, 9, 21, null]`。

实现注记（2026-09 实测）：数值列的**空单元格会被映射校验拒绝**（含非目标数值列），先确认字典也不行；缺失必须用字典声明的**缺失码**表示（例如 `-1`）。用缺失码替换 `null` 后，分析仍应得到 `validCount=4 / missingCount=1`，且 `0` 计入有效值。

```text
sampleCount=5, validCount=4, missingCount=1
mean=8
sample variance=90, sample SD=√90
Q1=1.5, median=5.5, Q3=12
min=0, max=21
```

- [ ] `0` 不得被当作缺失；SD 不得误标为 SE；null 不进入有效值分母。

### ST-B5：原值类型与分类分母

原值依次为：`"01", "1", 1, false, 0, "01", null`，只有 null 配置为缺失。

- [ ] 五个有效编码的计数依次为 `[2,1,1,1,1]`，`validCount=6`、`missingCount=1`。
- [ ] 字符串 `"1"` 与数字 `1`、布尔 `false` 与数字 `0` 不得因字符串化而合并。

### ST-B6：分层估计与标准误

总体分两层：A 层值 `[0,2,4,6,8,10]`，故 `N_A=6, S_A²=14`，抽 1 个值 2；B 层值 `[10,20,30,40]`，故 `N_B=4, S_B²=500/3`，抽 2 个值 10、40。

```text
estimate = 0.6×2 + 0.4×25 = 11.2
variance = 0.6²×(1−1/6)×14/1
         + 0.4²×(1−2/4)×(500/3)/2
         = 10.866666666666667
SE = 3.296462750686964
```

- [ ] 不能用总体 `N/n` 权重代替各层 `N_h/n_h`；每层 FPC 必须单独计算。

### ST-B7：系统抽样不能套用 SRS 标准误

按顺序排列总体 `[0,100,0,0,100,0]`，`N=6, n=2, K=3`。三个等宽随机起点区间对应样本均值 `[0,100,0]`。

```text
系统设计期望 = 100/3
系统设计 SE = sqrt(((0−100/3)²+(100−100/3)²+(0−100/3)²)/3)
              = 47.14045207910317
```

- [ ] 精确随机起点计算应得到上述 SE；若套 SRS 公式会得到不同结果，应判失败。
- [ ] 将总体顺序打乱后系统设计 SE 可以变化，页面不得声称其与排序无关。

### ST-B8：PPS Hájek 比估计与潜在偏差

总体 `y=[10,20,100]`、规模值 `[1,2,3]`、`n=1`，故 `π=[1/6,2/6,3/6]`。每次只选一个单位时 Hájek 估计等于该单位的 y。

```text
真实总体均值 = 130/3 = 43.333333333333336
估计量的设计期望 = Σπ_i y_i = 58.33333333333333
设计 SE = sqrt(Σπ_i(y_i−58.3333...)²) = 41.79978734661484
```

- [ ] 各随机起点区间的选择单位、纳入概率、Hájek 点估计和精确 SE 与枚举一致。
- [ ] 该例必须允许看出 Hájek 比估计可能有偏；产品不能把“设计 SE 已精确计算”表述成“估计无偏”。

### ST-B9：非等权点估计

连续值 `[2,10,40]`、设计权重 `[6,3,1]`：

```text
unweighted mean = 52/3
weighted mean = (6×2+3×10+1×40)/(6+3+1) = 8.2
```

分类值 `[A,B,B]` 使用同一权重：加权比例 `A=0.6, B=0.4`，原始频数仍为 `A=1, B=2`。

- [ ] 数值和标签均正确，索引与权重不可错位。

## 3.1 深度 dogfood 补充规则（2026-09 实测）

- **抽样世代与失效规则**：抽样结果写入（包括服务端写入 PPS 不适用标记）和阶段 ≤3 重开会使 `samplingGeneration` 前进；阶段 3 完成本身只推进实验 `version`，不额外推进抽样世代。`saved_analysis.stale` 由“世代或字典来源/revision 不一致”判定。因此“重新抽样后旧分析仍可引用”应判失败，而“上游重开后报告草稿被清空、阶段 4 重开保留草稿”是预期语义。
- **分析保存门槛**：需要有效字典、`requestId` 与完成阶段 3 之后的 `observedVersion`；同一 `requestId` 重试幂等（返回同一条记录、不新增行），不同 `requestId` 才会新增；阶段 4 完成后保存分析返回 409 `EXPERIMENT_LOCKED`（必须在完成阶段 4 前保存）。
- **PPS 规模合法性两层校验**：发布时要求“每个单位都为正数”的可用规模变量，执行 PPS 抽样时再次逐行校验；替换总体字节后再抽样必须被 400 拒绝且不产生新的 PPS 结果。
- **四种设计的精确口径**：系统抽样 SE 用精确随机起点积分（含打乱顺序后 SE 变化），PPS 用 Hájek 比估计并精确积分；n=1 时 Hájek 估计等于被选单位的 y，禁止退回 SRS 公式。
- **多类别展示**：核心计算先在完整类别空间计算代表性指标；图表超过 20 类时按总体占比保留头部类别并聚合尾部，所有方法共用同一映射，目标类别强制保留，聚合标签不得覆盖真实类别名。

## 3.2 教师与学生联动组合

每组都从教师创建并发布模板开始，分配任务后由学生规划、抽样、提交，再由教师批改。核对教师设置的研究目标、方法的必选/可选/禁用状态、PPS 规模变量白名单、评分权重与学生页面/API 一致；禁用方法的服务端调用应拒绝。估计值应独立计算，并与学生结果、提交快照、教师批改页和导出一致。

| 主目标 | 方法组合 | 特别检查 |
| --- | --- | --- |
| 均值 | 简单随机必选＋系统抽样必选 | 系统抽样使用总体原始顺序和随机起点，禁用 PPS/分层 |
| 比例 | 简单随机必选＋分层必选 | 按 `N_h/N` 合并各层目标类别比例，禁用系统/PPS |
| 均值 | 简单随机必选＋PPS 必选 | 规模变量逐行大于零且不是目标变量；核对纳入概率、设计权重和 Hájek 估计 |
| 比例 | 四种方法均必选 | 四种结果均冻结；教师批改和学生成绩页展示同一目标类别、估计值与精度提示 |

- [ ] 教师映射拒绝常量均值、总体中不存在的目标类别和仅一个类别的分层字段；研究合同与目标映射冲突时拒绝发布。
- [ ] PPS 白名单拒绝目标变量及含零规模值的字段；无效设置不能部分保存。
- [ ] 演示种子里的每份已提交、已批改或被驳回实验都冻结 `targetMetrics`；种子自检及教师、学生页面均能读到同一目标估计表。
- [ ] 提交后修改已发布模板被拒绝；教师评分权重计算所得总分与学生结果及成绩导出一致。

## 4. 专业检查项

### T. 研究目标、分析单位和变量

- [ ] **ST-T01 / S0**：一行确实对应一个分析单位；重复测量使用记录级唯一 ID，不把同一对象多行误称为独立个体。
- [ ] **ST-T02 / S0**：主目标恰好一个，且仅为均值或明确类别比例；总量、中位数、回归、因果效应、多目标联合精度不能通过改标签伪装成受支持目标。
- [ ] **ST-T03 / S0**：比例目标类别在完整总体中真实存在；类别比较规则对空格、NFKC 归一化和大小写的处理与教师预览一致。
- [ ] **ST-T04 / S0**：均值目标全列非缺失、可解析为有限数、方差大于 0 且尺度可可靠计算；失败时不使用默认方差。
- [ ] **ST-T05 / S0**：PPS 规模值逐行严格为正且不与主目标相同；分层字段无缺失并具有 2–20 个唯一层。
- [ ] **ST-T06 / S1**：替换总体、改变字段角色或目标解释后，来源标识变化，并强制重新配置/确认；只改无关说明不应改变统计来源。
- [ ] **ST-T07 / S0**：问卷试填答案无论如何变化，都不筛选、截断或改写总体、抽样框和分析结果。

### P. 样本量规划

- [ ] **ST-P01 / S0**：分别执行 ST-B1、ST-B2、ST-B3，逐项核对 raw 中间值、展示取整值、最终邀请数和预期完成量。
- [ ] **ST-P02 / S0**：比例误差始终按百分点解释，均值误差始终使用目标变量原单位；API、页面标签、公式和冻结快照不能混用 5、0.05 或百分号。
- [ ] **ST-P03 / S0**：置信水平只接受 90%/95%/99%，z 分别为 1.645/1.96/2.576；**接受路径（阶段完成与提交校验）必须拒绝**非法值，仅历史数据归一化（`normalizeConfidenceLevel`/`zForConfidenceLevel`）允许回退到 95%。
- [ ] **ST-P04 / S0**：`deff` 增大不能使所需样本量减少；误差限收紧或置信水平提高不能使样本量减少；无回答率增大不能使邀请数减少。
- [ ] **ST-P05 / S0**：`p` 与 `1−p` 得到相同规划量；在相同条件下 `p=0.5` 不小于其他 p 的规划量。
- [ ] **ST-P06 / S0**：发放量封顶 N 后重新计算实际可达误差；若仍超过目标，必须显示“精度不可达”，不能只显示已达到 N。
- [ ] **ST-P07 / S0**：存在无回答时“向全部 N 个单位发放”不等于完成普查，预期完成量、FPC 和 `census` 状态不能按邀请数误判。
- [ ] **ST-P08 / S0**：阶段完成和最终提交都用当前总体重新验证均值方差；覆盖舍入边界及 `σ²`/`S²` 转换。
- [ ] **ST-P09 / S1**：N=1、N=2、规划量接近 N、极小/极大误差限时无除零、负方差、NaN 或 Infinity。
- [ ] **ST-P10 / S1**：高级规划工具必须分别说明目标量、假设、数据来源、适用范围和限制；不能让辅助的 CV、成本或整群计算自动改变主流程样本量。

### S. 抽样执行与设计重放

- [ ] **ST-S01 / S0**：简单随机样本恰有 n 个不重复、合法索引；n=N 时每个单位恰好一次；固定种子可复现。
- [ ] **ST-S02 / S1**：对小总体枚举或大量重复抽样，简单随机各单位纳入频率近似 n/N；交换总体行序后不产生固定位置偏好。
- [ ] **ST-S03 / S0**：系统抽样严格使用 `K=N/n`、`index_j=floor(r+jK)`、`0≤r<K`，对非整数 K 仍恰好得到 n 个唯一合法索引。
- [ ] **ST-S04 / S0**：系统抽样保存的间隔、随机起点、种子、索引和行内容能相互重放；任一字段被篡改应拒绝后续分析。
- [ ] **ST-S05 / S0**：分层样本量逐层满足 `1≤n_h≤N_h`，总和等于目标 n；每层内部为不放回简单随机抽样，不能遗漏小层。
- [ ] **ST-S06 / S0**：比例、等额、奈曼分配用非对称层规模和层内 SD 手算核对；容量约束后剩余名额仍按正确目标重新分配。
- [ ] **ST-S07 / S0**：PPS 对所有单位给出 `0<π_i≤1`、`Σπ_i=n`；必入单位先移出再对剩余样本量重新计算，不因浮点舍入产生假 π=1。
- [ ] **ST-S08 / S0**：PPS 样本恰有 n 个唯一单位；所存 `π_i` 与所选索引一一对应；`1/π_i` 不是规模值本身，也不是单次抽取概率的倒数。
- [ ] **ST-S09 / S1**：规模值跨极端数量级时，无法可靠表示的设计必须明确不可用或按配置降级；不能返回伪造的确定性样本或 SE=0。
- [ ] **ST-S10 / S0**：任何客户端伪造的行、索引、权重、纳入概率、层身份或随机结果都不能成为可信分析来源；服务端按总体与设计重放。

### E. 估计量、标准误和误差半宽

- [ ] **ST-E01 / S0**：分别执行 ST-B6、ST-B7、ST-B8、ST-B9，核对点估计和设计 SE，不允许四种设计共用 SRS 公式。
- [ ] **ST-E02 / S0**：比例目标用完整总体的 0/1 方差计算设计 SE；样本中 0 个目标时估计可为 0，但只要设计方差非零，SE 不能错误变成 0。
- [ ] **ST-E03 / S0**：总体全属于目标类别时 SE 可为 0，但 n<N 时不能标记为普查。
- [ ] **ST-E04 / S0**：分层估计和 SE 使用真实 `N_h`、`n_h` 和层内 `S_h²`；单单位层或常量层是已知零方差，不等于缺失统计量。
- [ ] **ST-E05 / S0**：PPS 使用 Hájek 比估计而不是 Horvitz–Thompson 总量除以 N；必入单位、n=1、均衡规模和普查均有独立基准。
- [ ] **ST-E06 / S0**：系统和 PPS 的精确积分覆盖随机起点的全部分段；不能用少量 Monte Carlo 重复掩盖稀有但高影响区间。
- [ ] **ST-E07 / S0**：`marginOfError=z×SE` 使用计划选择的 z；更换置信水平只按规则改变半宽，不重写点估计。
- [ ] **ST-E08 / S1**：`n_eff` 满足 `0<n_eff≤N`；SE=0 或总体方差=0 时按当前教学约定显示 N；实际 n 与等效 n 必须分开展示。
- [ ] **ST-E09 / S0**：普查条件以实际覆盖全部 N 个单位判断；只因 SE 数值下溢为 0、样本量计划封顶或估计恰等于真值，不能标成普查。
- [ ] **ST-E10 / S0**：页面、API/数据库冻结值、提交快照和师生详情中的估计值、SE、半宽、置信水平和单位完全一致；任何实际导出这些指标的 CSV/XLSX 也须一致。当前学生样本 CSV 只导出样本行及 PPS 的 π/权重，不得把未导出的统计指标记为已核对。

### A. 描述统计、缺失和类别

- [ ] **ST-A01 / S0**：执行 ST-B4、ST-B5；检查 `sampleCount=validCount+missingCount`、样本 SD 分母 n−1 和 R7 插值。
- [ ] **ST-A02 / S0**：有效值为 0 个时统计量为 null；1 个时均值/极值有效但样本 SD 为 null；不能用 0 填充不可用量。
- [ ] **ST-A03 / S0**：缺失编码仅匹配同类型 JSON 标量；`"01"`、`"1"`、`1`、`false`、`0` 保持不同，缺失与有效类别不得重叠。
- [ ] **ST-A04 / S0**：加权值/权重成对重排后结果不变；所有权重乘同一正数后结果不变；值和权重错位必须被基准发现。
- [ ] **ST-A05 / S0**：正比例改变连续变量单位后，均值、SD、分位数和 SE 同比例变化，样本量/计数/比例不变。
- [ ] **ST-A06 / S0**：分类各类别计数之和等于有效数，比例之和在浮点容差内为 1（或展示为 100%）；零频类别不消失。
- [ ] **ST-A07 / S1**：类别超过 20 时仅图表聚合，完整统计和代表性指标仍按全类别空间计算；真实类别名“其他”不能被聚合标签覆盖。
- [ ] **ST-A08 / S0**：加权结果不展示未实现的 SD、分位数、SE 或区间；任何这类数值出现都需要可审计的新方法定义和验证。

### I. 统计解释与教学警示

- [ ] **ST-I01 / S0**：“设计标准误”和“教学误差半宽”明确依赖教师已知的完整有限总体，不能描述成现实调查中仅凭当前样本即可得到。
- [ ] **ST-I02 / S0**：误差半宽不应笼统保证覆盖率、无偏性、代表性或数据质量；PPS Hájek 比估计可能有偏，系统抽样覆盖取决于排序和随机起点。
- [ ] **ST-I03 / S1**：`n_eff<30`、实际 n<30、稀有事件/非事件少于阈值、高影响单位、系统抽样、PPS 和超过规划误差限时出现相应 caution 原因。
- [ ] **ST-I04 / S1**：即使 `n_eff≥30`，实际 n<30 仍保留小样本警示；“ok”只能表示当前规则未触发警示，不能翻译成“结论可靠无偏”。
- [ ] **ST-I05 / S1**：比例目标接近 0/1 或样本观察为 0/1 时，明确提示对称正态区间可能覆盖不足；不能把截断到 `[0,1]` 当作覆盖保证。
- [ ] **ST-I06 / S0**：回答率只用于规划邀请量，不代表无回答偏差已消除；高回答率也不能自动证明无偏或有代表性。
- [ ] **ST-I07 / S0**：总体真值与样本估计并列展示时明确是教学环境特权；学生报告不能把估计误差与现实中未知真值混淆。
- [ ] **ST-I08 / S2**：所有统计量具有清楚名称、分母、单位、加权状态、抽样方法和小数精度；同一概念在四阶段和师生端用词一致。

### N. 数值稳定性与复现性

- [ ] **ST-N01 / S0**：测试正负大数抵消、全零、常量、`1e-320` 附近、`1e300` 附近和高动态范围权重；结果要么与高精度参考一致，要么明确不可用。
- [ ] **ST-N02 / S0**：任何 JSON、数据库、页面或导出中不得出现 NaN、Infinity、`-Infinity` 或把下溢后的假 0 当成精确结果。
- [ ] **ST-N03 / S1**：总体行和样本行成对平移/缩放时，稳定求和不应出现明显灾难性消减；极端失败应保留原始输入作为回归夹具。
- [ ] **ST-N04 / S0**：相同总体字节、字段解释、方法、参数和种子重放得到相同索引与结果；总体内容或解释变化后来源哈希必须变化。
- [ ] **ST-N05 / S0**：同种子重抽会产生新抽样代次并使旧分析过期；统计结果相同不能让旧证据重新变成当前证据。
- [ ] **ST-N06 / S1**：显示层舍入不能反向写入计算；总和显示为 99.99%/100.01% 时需合理说明或最大余数展示，但底层比例保持未舍入值。

## 5. 不应被产品声称为已支持

测试时应主动搜索页面、帮助文案、导出标题和报告模板；出现下列无方法依据的结论，应按 S0/S1 报告：

- 总量、比率、中位数、回归系数、相关、假设检验、p 值、因果效应或多个并列主要目标的推断。
- 复杂缺失机制调整、无回答加权、校准、后分层或插补已经消除偏差。
- PPS 的加权标准差、分位数、置信区间，或系统/PPS 设计天然无偏且保证覆盖。
- 试填问卷答案可作为正式调查观测，或可与总体文件联合估计。
- 有放回抽样、整群/多阶段抽样已在主流程执行；当前高级规划展示不等于这些设计已实现。
- 根据一次样本接近总体真值就宣称抽样方法更优；方法比较应基于设计性质或重复抽样表现。
- 把图表“代表性差异”辅助指标当成标准统计检验、总体误差或无偏性证明。

## 6. 建议的统计回归组合

1. **每次提交**：ST-B1、ST-B3、ST-B4、ST-B6、ST-B7、ST-B8、ST-B9，以及 ST-T02、ST-P02、ST-S07、ST-E02、ST-E05、ST-A03、ST-I01、ST-N02。
2. **抽样算法变化**：ST-S01–ST-S10、ST-E01–ST-E09；小总体枚举全部随机起点/可行样本，大总体固定种子做性能与稳定性。
3. **规划或展示变化**：ST-P01–ST-P10、ST-I01–ST-I08；同时核对 raw API 与四舍五入 UI。
4. **解析、字典或总体变化**：ST-T01–ST-T07、ST-A01–ST-A08、ST-N01–ST-N06；CSV 和 XLSX 使用同一逻辑数据交叉验证。

```sh
bun run test:unit
bun run test:db
bun run test:teaching
```

退出标准：S0 为 0 个失败；S1 全部通过或有具名风险接受；每个修复都有一个非对称、能让错误公式失败的独立基准；统计方法或解释变化已同步更新[课题模型](../RESEARCH_MODEL.md)。

## 7. Web 参考资料

- [Statistics Canada, Survey Methods and Practices](https://www150.statcan.gc.ca/n1/pub/12-587-x/12-587-x2003001-eng.pdf)：抽样框、概率抽样、分层、系统抽样、PPS、估计和调查误差的综合参考。
- [United Nations, Designing Household Survey Samples: Practical Guidelines](https://unstats.un.org/unsd/demographic/sources/surveys/handbook23june05.pdf)：有限总体调查的样本设计、设计效应、PPS、权重和实施指南。
- [Penn State STAT 506: Stratified Sampling](https://online.stat.psu.edu/stat506/Lesson06)：分层均值/总量估计、方差与最优分配参考。
- [Penn State STAT 506: Cluster and Systematic Sampling](https://online.stat.psu.edu/stat506/Lesson07)：系统抽样对总体排序与周期性的敏感性参考。
- [NIST/SEMATECH e-Handbook of Statistical Methods](https://www.itl.nist.gov/div898/handbook/dtoc.htm)：描述统计、分布、区间与数值验证的通用参考。
- [AAPOR Standard Definitions](https://aapor.org/standards-and-ethics/standard-definitions/)：区分回答率、合作率和无回答影响；回答率本身不是无回答偏差的充分证明。

外部资料用于校验统计学原则；本项目特有的估计目标、公式顺序、设计实现和教学限制仍以当前代码与[课题模型](../RESEARCH_MODEL.md)为准。
