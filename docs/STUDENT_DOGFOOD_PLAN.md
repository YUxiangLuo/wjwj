# 学生端 Dogfood 计划（第四轮 · 新 seed + 教师联动）

背景：新 seed 把演示数据换成「2026 校园学习与生活状况调查」，学生端面对的四个子课题各自代表一种抽样/估计形态；同时教师端已具备删除影响面确认、归属隔离、导出内容校验等能力。本轮学生端 dogfood 的目标是**学生视角端到端 + 教师联动对账**。

工具分工：
- 已有深度骨架 `scripts/test-teaching-flow.ts`（浏览器驱动、临时库、证据目录）：覆盖学生四阶段 UI 门禁、草稿恢复、网络/渲染失败恢复、提交、教师驳回、学生重交、教师评分、学生查看成绩、导出内容。本轮直接复用并纳入证据。
- 本轮新增：新 seed 的**四类课题差异**、任务门禁（未开放/已截止）、跨学生越权、以及教师侧统计口径对账。

> 原则沿用：行为与终态优先；每条给出证据与判据；发现缺陷即修复并补回归测试。

## 场景矩阵

### S1 任务大厅与课题详情
1. 主班学生登录 → 任务大厅可见 3 个任务（学习时长/阅读时长/就业比例），未开放的比例任务不出现为可进入状态。
2. 课题详情展示：目标总体、分析单位、研究问题、推荐题、附件可下载。
3. 已截止/未开放任务的进入尝试被拒（`TASK_NOT_OPEN` / `TASK_DEADLINE`），且页面给出可读提示。
4. 判据：可见性与 `task.open_time/deadline` 完全一致，无越权可见。

### S2 阶段一：问卷设计
5. 模板选择 → 编辑 → 受访者视角试填必须逐题交互、不自动跳题 → 保存后进入下一阶段。
6. 理解检查答对才解锁；快速自检须全部答对；草稿在刷新/换页后仍在。
7. 判据：门禁在 UI 与服务端两侧一致（阶段只能顺序推进）。

### S3 阶段二：样本量规划（沉浸式）
8. 「猜测可跳过」但理解检查必答；答错不解锁，进度（已掌握 n/6）刷新后不丢。
9. 规划结果与生产函数一致（学习时长 49 / 阅读时长 15）。
10. 小总体（阅读 N=24）显示普查提示；PPS 不适用的总体在策略与规划中给出说明。
11. 判据：推荐样本量 = `sample-plan` 生产计算；提示语与实际总体规模一致。

### S4 阶段三：抽样执行
12. 简单随机必做并生成服务端审计记录；系统抽样、PPS（规模变量=月生活费）、分层可选。
13. PPS 必做课题（食堂等待时间）必须完成 PPS；PPS 不适用课题（阅读时长）不出现 PPS 入口。
14. 抽样动画可跳过并可返回；结果数据表宽度适配且不溢出；重抽/上限受控。
15. 判据：抽样结果 `serverGenerated`、可复现（种子与索引落库），策略与结果过滤一致。

### S5 阶段四：分析与报告
16. 均值目标与比例目标的估计、标准误、置信区间、方法比较均渲染；PPS 用精确设计积分（非蒙特卡洛）。
17. 图表/结果导出可用；报告编辑器保存草稿（localStorage 键含实验版本）。
18. 判据：分析指标与抽样结果自洽，报告校验通过才能提交。

### S6 提交与预览
19. 预览页展示四阶段产出的快照；提交前缺项被拒；提交后转只读。
20. 判据：`status=submitted` 且 `submission_snapshot` 与线上记录一致（快照不可变）。

### S7 教师联动对账（本轮重点）
21. 教师端「任务进度/概览/导出」的学生状态与学生对账一致（不超过、不缺失）。
22. 教师驳回 → 学生看到驳回通知与理由 → 学生重交 → 教师看到 v2 且旧评分清空。
23. 教师评分 → 学生成绩详情显示总分与评语；导出 xlsx 内容与该分数一致。
24. 教师无法读取他班学生的实验（越权 404），学生无法读取他人实验。
25. 判据：同一事实（状态/分数/时间）在学生端、教师端、导出、DB 四处一致。

### S8 对抗与恢复
26. 学生 A 直接访问学生 B 的实验/阶段接口 → 404/403，且不产生写入。
27. 截止后新写入被拒（`TASK_DEADLINE`）；已通过检查的请求可完成。
28. 会话：退出后回退、跨角色 Cookie 隔离、过期会话整页登录。
29. 脏输入：问卷空题干/超量选项、报告超长、非法抽样参数、超大总体文件 → 明确拒绝。
30. 判据：失败路径均有明确反馈，不留半写入。
