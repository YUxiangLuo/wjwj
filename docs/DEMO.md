# 内部演示指南

**演示模式公开演示凭据，不能对外部署。** 正式教学初始化使用 [README](../README.md) 的 `db:bootstrap-admin`，不要写入演示 seed。

## 准备与启动

仅在独立的空演示库中运行（先确认 `.env` 的 `DATABASE_URL`）：

```sh
bun run db:migrate
bun run db:seed:demo
bun run db:seed:check
bun run start:demo
```

`start:demo` 同时启用前端预填和服务端随机学生凭据端点。普通 `start` 不启用该模式，普通生产包不包含演示密码。

- `db:seed` 只在 `DEMO_MODE=1` 下允许执行，`db:seed:demo` 已显式设置该变量。
- seed **非幂等且只支持空库**；失败可能留下部分记录或文件，不要直接重跑。确需丢弃演示数据并重建时，按 [DATABASE.md](../DATABASE.md) 的确认流程使用 `db:reset:demo`，该操作不会清理 `storage/`。
- `SEED_NOW=2026-06-15T08:30:00.000Z` 可固定相对时间锚点；未设置时用当前时间。固定过去的锚点可能使有截止时间的任务已过期。

## 课题与状态覆盖

| 模板 | 总体与抽样特点 |
| --- | --- |
| 本科生每周学习时长 | 200 名本科生的每周学习时长均值/PPS，月生活费作规模；当前主班与历史班各有任务 |
| 学生每周阅读时长 | 24 名学生的阅读时长均值，含零值，无合格 PPS 规模列；主班任务 |
| 毕业生直接就业意向比例 | 160 名毕业生的直接就业比例/PPS，分层必做；主班开放、副班尚未开放 |
| 食堂午间等待时间 | 96 个食堂服务时段的平均等待时间/PPS，PPS 必做；公共管理班任务 |
| 新生数字素养调查（设计阶段） | 只有问卷、没有总体数据的未发布草稿 |

主任务「本科生每周学习时长」在班级成员中精确覆盖 8 个进度桶：未开始 3 人，stage1–4、已提交、已批改、已驳回各 1 人。主任务推荐样本量为 49；「学生每周阅读时长」任务样本量由生产计算函数得到 9。阶段 4 与终态实验只存 compact 重放索引，不重复保存总体行。

## 扩充研究课题

`scripts/add-demo-research-topics.ts` 可增补 10 类课题，默认使用 T001 并分配到现有统计学、公共管理演示班级，任务无截止时间，不重置原有数据。

```sh
DEMO_BASE_URL=http://127.0.0.1:3000 \
DEMO_CATALOG_MANIFEST=/safe/path/demo-research-manifest.json \
bun run scripts/add-demo-research-topics.ts
```

| --- | --- | --- |

数据定义在 `scripts/demo-research-catalog.ts`，包含合成 CSV、研究合同、6 道推荐题、精度建议、策略与报告提示。模板 ID 由数据库分配，不是固定编号。

**清单用于中断续跑与避免重复创建，重复执行必须保留同一清单。** 脚本不覆盖清单之外的同名课题。扩充后不再符合默认 seed 固定计数，应按清单验证新增任务，不能因 `db:seed:check` 数量不符而执行 reset。
