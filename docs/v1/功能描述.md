# 抽样统计虚拟仿真系统 - 功能详细描述

## 文档说明

- **项目名称**：抽样统计虚拟仿真教学系统
- **版本**：V2.0
- **文档目的**：详细描述系统各角色端的功能、页面结构、操作流程和业务规则，为后续开发提供稳定的功能基准

---

## 系统概述

### 核心理念

本系统旨在构建一个高度仿真的统计学抽样教学环境，通过「封闭式管理」架构，模拟真实的调研流程：从教师发布任务，到学生规划样本、实施抽样、分析误差，最终由教师进行多维度的评价。

核心设计原则：
- **Learning by Doing**：让学生在实践中理解理论，在对比中深化认知
- **过程导向**：关注学生的操作过程和决策逻辑，而非仅看结果
- **可视化对比**：通过图表直观展示不同抽样方法的效果差异
- **闭环反馈**：自动评分 + 人工点评相结合

### 用户角色

| 角色 | 职责 | 典型操作 |
|------|------|----------|
| 系统管理员 | 平台基础设施管理 | 学期配置、班级创建、教师管理、系统监控 |
| 教师 | 教学内容准备与评价 | 数据上传、课题配置、任务发布、作业批改 |
| 助教 | 协助教师批改作业 | 查看学生进度、批改作业、驳回重做 |
| 学生 | 实验操作与学习 | 问卷设计、样本量规划、抽样执行、报告撰写 |

### 系统架构

系统采用B/S架构，包含四个用户端：
- 学生端：线性向导式实验流程
- 教师端：课题管理与作业评价
- 助教端：协助批改作业（权限受限的教师端）
- 管理员端：系统基础设施管理

## 学生端详细功能描述

### 一、登录模块

#### 1.1 登录页面

**页面元素：**
- 学号输入框
- 密码输入框
- 登录按钮
- 忘记密码提示文字（提示联系教师或管理员重置）

**登录流程：**
1. 输入学号和密码，点击登录
2. 系统验证账号密码是否正确
3. 验证失败：提示「学号或密码错误」
4. 验证成功：检查是否首次登录

#### 1.2 首次登录强制改密

**触发条件：** 账号的「首次登录」标记为true

**页面元素：**
- 提示文字「首次登录，请修改密码」
- 新密码输入框
- 确认密码输入框
- 确认按钮

**密码规则：**
- 长度8位以上
- 必须包含字母和数字
- 两次输入必须一致

**完成后：**
- 更新密码
- 将「首次登录」标记改为false
- 跳转到任务大厅

### 二、任务大厅

#### 2.1 页面布局

**顶部导航栏：**
- 系统名称/Logo
- 当前用户姓名
- 退出登录按钮

**公告区域（如有未读公告）：**

- 点击可查看公告详情

**主内容区：**
- 任务卡片列表

#### 2.2 任务卡片

**每张卡片显示：**
- 课题名称
- 课题背景描述（截取前50字）
- 发布时间
- 截止时间（如已设置）
- 剩余时间（如「还剩3天」或「已截止」）
- 当前状态标签

**状态标签及含义：**

| 状态 | 含义 |
|------|------|
| 未开始 | 学生尚未点击进入 |
| 进行中 | 已开始但未提交 |
| 已提交 | 已提交，等待批改 |

- 每条记录显示：提交时间、状态（已批改/被驳回）、得分（如有）

### 四、阶段一：问卷设计

#### 4.1 整体结构

问卷设计采用向导式流程，分为四个步骤：
1. 欢迎语设置
2. 题目设计
3. 结束语设置
4. 预览确认

顶部显示步骤进度条，可点击已完成的步骤回退查看，但修改需确认。

#### 4.2 步骤一：欢迎语设置

**页面元素：**
- 问卷标题输入框（必填，限制50字）
- 欢迎语富文本编辑器（必填，限制500字）
- 下一步按钮

**欢迎语用途提示：**
- 告知受访者调查目的
- 说明问卷大致用时
- 承诺数据保密等

#### 4.3 步骤二：题目设计

**页面布局：**
- 左侧：已添加的题目列表（可拖拽排序）
- 右侧：题目编辑区域
- 底部：推荐题目参考区域（可折叠）

**添加题目方式：**

**方式一：自建题目**
- 点击「添加题目」按钮
- 选择题目类型：判断题、单选题、多选题、满意度量表
- 填写题目内容

**方式二：引用推荐题目**
- 浏览教师设置的推荐题目列表
- 点击「使用」直接添加到问卷
- 添加后可修改题目内容

**各题目类型的配置：**

**判断题：**
- 题目内容（必填）
- 选项固定为「是」「否」

**单选题：**
- 题目内容（必填）
- 选项列表（至少2个，最多10个）
- 每个选项可编辑文字
- 可添加/删除选项

**多选题：**
- 题目内容（必填）
- 选项列表（至少2个，最多10个）
- 可设置最少选择数和最多选择数（可选）

**满意度量表：**
- 题目内容（必填）
- 量表范围固定为1-10
- 可设置两端标签（如「非常不满意」-「非常满意」）

**题目列表操作：**
- 拖拽调整顺序
- 点击编辑
- 点击删除（需确认）
- 显示题目序号（自动编号）

#### 4.4 步骤三：结束语设置

**页面元素：**
- 结束语富文本编辑器（必填，限制500字）
- 可包含致谢词、联系方式等

#### 4.5 步骤四：预览确认

**页面功能：**
- 模拟真实问卷的展示效果
- 显示完整问卷：欢迎语 → 所有题目 → 结束语
- 预览模式下不可编辑

**自动质量检测：**

检测规则：
- 题目数量是否在合理范围（如5-30题）
- 题目类型是否有多样性（不能全是同一种类型）
- 欢迎语和结束语是否已填写
- 单选/多选题的选项数量是否合理

检测结果展示：
- 通过：显示「问卷结构合理」
- 不通过：显示具体问题列表，如「题目全部为单选题，建议增加其他题型」

初步评分：给出问卷设计的机器评分（供参考）

**页面按钮：**
- 「返回修改」：回到题目设计步骤
- 「确认完成」：锁定问卷设计，进入下一阶段

**确认完成时的提示：**
- 弹窗提示「确认后问卷设计将被锁定，如需修改需返回本阶段重新设计，届时后续阶段的数据将被清空。确定继续吗？」
- 用户确认后保存并进入阶段二

### 五、阶段二：样本量规划

#### 5.1 页面布局

**信息展示区：**
- 总体规模N（来自教师上传的Excel数据行数）
- 显示为「本次调查的总体规模为 N = 10,000 人」

**参数输入区：**

| 参数 | 输入方式 | 说明 |
|------|----------|------|
| 置信水平 | 下拉框 | 选项：90%、95%、99%，默认95% |
| 允许误差 | 输入框或滑块 | 范围1%-10%，默认5% |

**计算结果展示区：**
- 显示计算公式（教学目的）：`n = (Z² × p × (1-p)) / E²`
- 显示各参数含义：
  - Z：对应置信水平的Z值（90%→1.645，95%→1.96，99%→2.576）
  - p：取0.5（最大方差假设）
  - E：允许误差
- 显示计算结果：「建议样本量 n = 384」

**最终决策区：**
- 提示文字「您可以根据实际情况调整最终样本量」
- 最终样本量输入框
- 输入范围限制（如最小30，最大不超过总体规模的50%）

#### 5.2 交互逻辑

- 修改置信水平或允许误差时，自动重新计算建议样本量
- 最终样本量输入框默认填入建议值，学生可修改
- 修改最终样本量时，实时提示该值与建议值的偏差

#### 5.3 确认完成

点击「确认并进入下一阶段」按钮：
- 保存样本量规划数据
- 弹窗提示「样本量确定后将作为后续抽样的基准。确定继续吗？」
- 确认后锁定本阶段，进入阶段三

### 六、阶段三：抽样执行

#### 6.1 页面布局

**顶部信息：**
- 显示目标样本量n（来自阶段二）
- 显示总体规模N

**三种方法Tab或卡片：**
- 简单随机抽样
- 系统抽样
- 分层抽样
- 每种方法显示完成状态（已完成✓ / 未完成）

**底部按钮：**
- 「完成本阶段」：三种方法都完成后才可点击

#### 6.2 简单随机抽样

**说明文字：**
- 简要介绍简单随机抽样的原理
- 「从N个总体中随机抽取n个样本，每个个体被抽中的概率相等」

**操作区域：**
- 显示「将从 10,000 人中随机抽取 400 人」
- 「执行抽样」按钮

**执行后：**
- 显示抽样完成提示
- 显示样本数据预览（表格形式，显示前10条，可滚动查看更多）
- 显示「重新抽样」按钮（点击后覆盖上次结果）

#### 6.3 系统抽样

**说明文字：**
- 简要介绍系统抽样的原理
- 「按固定间隔K从总体中抽取样本」

**参数输入区：**
- K值输入框
- 实时提示：
  - 显示建议K值：「建议 K = N/n = 10000/400 = 25」
  - 输入K值后实时显示：「间隔K=25，预计抽取约 400 人」
  - K值不合理时警告：「K值过大，样本量将不足」或「K值过小，样本量将超出目标」

**操作区域：**
- 「执行抽样」按钮

**执行时校验：**
- K必须为正整数
- K值导致的样本量与目标差异过大时给出警告，但允许执行

**执行后：**
- 显示实际抽取的样本数量
- 显示样本数据预览
- 显示「重新抽样」按钮

#### 6.4 分层抽样

**说明文字：**
- 简要介绍分层抽样的原理
- 「先按某特征将总体分层，再从各层中分别抽取样本」

**步骤一：选择分层变量**
- 下拉框列出所有教师标记为「分层变量」的字段
- 如「性别」「年级」「地区」
- 选择后显示各层统计信息

**步骤二：查看各层信息**

表格展示：

| 层 | 人数 | 比例 |
|------|------|------|
| 男 | 6,000 | 60% |
| 女 | 4,000 | 40% |

**步骤三：设定各层样本数**

快捷方式按钮：
- 「比例分配」：按总体比例分配样本（男240人，女160人）
- 「等额分配」：各层样本数相等（男200人，女200人）

手动调整：
- 每层一个输入框，可手动填写
- 实时汇总显示：「当前总样本量：400 人（目标：400 人）」
- 汇总不等于目标时警告：「总样本量与目标不一致」

**操作区域：**
- 「执行抽样」按钮（汇总等于目标时才可点击，或允许点击但给出警告）

**执行后：**
- 显示各层实际抽取数量
- 显示样本数据预览（带分层标记）
- 显示「重新抽样」按钮（重新抽样时回到选择分层变量步骤）

#### 6.5 完成本阶段

**条件：** 三种方法都至少执行过一次

点击「完成本阶段」：
- 保存三种方法的最终抽样结果
- 弹窗提示确认
- 进入阶段四

### 七、阶段四：分析与报告

#### 7.1 页面布局

分为三个区域：
- 图表展示区
- 数据导出区
- 报告撰写区

#### 7.2 图表展示区

系统自动生成的图表：

**针对数值变量（如收入、年龄）：**

**图表A：均值对比柱状图**
- 横轴：总体、简单随机、系统抽样、分层抽样
- 纵轴：均值
- 每个柱子上方显示具体数值
- 图表标题：「[变量名]均值对比」

**图表B：分布对比图**
- 四条曲线叠加在同一张图上
- 图例区分：总体、简单随机、系统抽样、分层抽样
- 横轴：变量值范围
- 纵轴：频率/密度
- 图表标题：「[变量名]分布对比」

**针对分类变量/分层变量（如性别、职业）：**

**图表C：比例对比柱状图**
- 分组柱状图
- 每组代表一个类别（如男、女）
- 组内四个柱子：总体比例、三种抽样方法的样本比例
- 图表标题：「[变量名]比例对比」

**综合指标：**

**图表D：误差对比表**
- 表格形式
- 列：三种抽样方法
- 行：各变量的误差（与总体真值的偏离百分比）
- 底部汇总：平均误差

**图表交互：**
- 鼠标悬停显示具体数值
- 可放大查看
- 可切换查看不同变量的图表（如果有多个数值变量）

#### 7.3 数据导出区

**导出选项：**
- 导出简单随机抽样样本（CSV）
- 导出系统抽样样本（CSV）
- 导出分层抽样样本（CSV）
- 导出全部样本（合并为一个CSV，带方法标记列）

**CSV内容：**
- 包含所有教师标记的字段
- 分层抽样的CSV额外包含分层标记

**用途提示：**
- 「可下载样本数据用于课后在SPSS、R等软件中进行深入分析」

#### 7.4 报告撰写区

**提示文字：**
- 「请根据上述图表，分析三种抽样方法的结果差异，说明哪种方法的结果最接近总体真值，并解释可能的原因。」

**富文本编辑器：**
- 支持基本格式：加粗、斜体、列表
- 字数限制：100-2000字
- 实时显示当前字数

#### 7.5 完成本阶段

点击「完成并预览报告」：
- 校验报告字数是否达到最低要求
- 生成预览

### 十一、阶段回退机制

#### 11.1 触发场景

学生在阶段二、三、四时，想回到之前的阶段修改

#### 11.2 回退操作

**入口：**

### 四、课题管理

#### 4.1 课题列表页

**显示内容：**
- 表格展示当前教师创建的所有课题
- 列：课题名称、状态（草稿/已发布）、数据行数、创建时间、操作

**状态筛选：**
- 全部/草稿/已发布

**操作按钮：**
- 草稿状态：编辑、删除、发布
- 已发布状态：查看、编辑（受限）、删除（软删除）

**顶部按钮：**
- 「创建课题」

#### 4.2 创建/编辑课题

采用分步骤表单：

**步骤一：基本信息**

表单字段：
- 课题名称（必填，限制100字）
- 背景描述（必填，富文本编辑器，限制5000字）
- 描述用途提示：介绍调研背景、目的、意义等

**步骤二：上传总体数据**

上传区域：
- 拖拽上传或点击选择文件
- 限制：仅支持.xlsx和.xls格式，最大100MB

上传流程：
1. 选择文件后自动上传
2. 显示上传进度
3. 上传完成后系统解析Excel

解析成功：
- 显示「解析成功，共X行数据，Y个字段」
- 显示字段列表预览

解析失败：
- 显示具体错误信息，如：
  - 「文件格式不支持」
  - 「文件内容为空」
  - 「第X行第Y列数据格式错误：[具体问题]」
  - 「存在空值：第X行[字段名]为空」
- 需重新上传

**步骤三：字段映射**

界面展示：
- 左侧：Excel中的所有字段列表
- 右侧：已选择的字段及其类型配置

操作方式：
- 从左侧勾选要使用的字段
- 为每个选中的字段设置类型

**字段类型说明：**

| 类型 | 用途 | 示例 |
|------|------|------|
| 分层变量 | 用于分层抽样的分组依据（必须是离散值） | 性别、年级、地区 |
| 数值变量 | 用于统计分析的连续型数据 | 收入、年龄、成绩 |
| 分类变量 | 用于频率统计的离散型数据 | 职业、学历、满意度等级 |
| 标识变量 | 唯一标识，不参与分析 | ID、编号 |

**校验规则：**
- 至少选择3个字段
- 至少有1个分层变量
- 至少有1个数值变量
- 分层变量的唯一值数量需在合理范围内（如2-20个）

**步骤四：辅助资料（可选）**

上传区域：
- 支持多文件上传
- 支持格式：图片（jpg/png/gif）、视频（mp4）、文档（pdf/doc/docx）
- 单文件限制：图片10MB，视频500MB，文档50MB

已上传列表：
- 显示文件名、类型、大小
- 可删除

**步骤五：推荐题目（可选）**

推荐题目列表：
- 表格展示已添加的题目
- 列：题目内容、题目类型、操作

添加题目：
- 「添加推荐题目」按钮
- 弹窗填写：
  - 题目类型选择：判断题、单选题、多选题、满意度量表
  - 题目内容输入
  - 选项设置（单选、多选题）
- 确认添加

编辑/删除题目：
- 点击操作按钮

**步骤六：评分权重（可选）**

三项权重设置：
- 问卷设计权重（%）
- 实验过程权重（%）
- 实验报告权重（%）

校验：
- 三项之和必须等于100%
- 可暂时不设置，批改时再设置

**保存/发布：**

底部按钮：
- 「保存为草稿」：保存当前内容，状态为草稿
- 「保存并发布」：保存后跳转到发布流程

#### 4.3 已发布课题的编辑限制

**可修改：**
- 基本信息（名称、背景描述）
- 辅助资料（增删文件）
- 推荐题目（增删改）
- 评分权重

**不可修改：**
- Excel数据文件
- 字段映射配置

尝试修改时：
- 相关区域显示为只读
- 提示「课题已发布，数据配置不可修改」

#### 4.4 删除课题

点击删除：
- 弹窗确认「确定删除课题XXX吗？」
- 已发布的课题额外提示「该课题已发布给X个班级，删除后教师和学生将无法在列表中看到该课题，但历史数据保留」

- 从列表中隐藏

### 附录C：三种抽样方法说明

**简单随机抽样 (Simple Random Sampling)**
- 原理：从总体N个单位中随机抽取n个单位，每个单位被抽中的概率相等
- 特点：最基础的抽样方法，操作简单
- 适用：总体同质性较高时

**系统抽样 (Systematic Sampling)**
- 原理：将总体按某种顺序排列，随机选择一个起点，然后每隔K个单位抽取一个
- 特点：操作简便，样本分布均匀
- 计算：K = N / n
- 适用：总体有自然排序时

**分层抽样 (Stratified Sampling)**
- 原理：先将总体按某特征分成若干层，再从各层中随机抽取样本
- 特点：保证各子群的代表性，精度较高
- 分配方式：比例分配、等额分配
- 适用：总体异质性较高，可按特征分层时
