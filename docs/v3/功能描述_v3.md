## 系统概述

### 核心理念

本系统旨在构建一个高度仿真的统计学抽样教学环境，通过「封闭式管理」架构，模拟真实的调研流程：从教师发布任务，到学生规划样本、实施抽样、分析误差，最终由教师进行多维度的评价。

核心设计原则：
- **Learning by Doing**：让学生在实践中理解理论，在对比中深化认知
- **过程导向**：关注学生的操作过程和决策逻辑，而非仅看结果
- **可视化对比**：通过图表直观展示不同抽样方法的效果差异
- **闭环反馈**：自动评分 + 人工点评相结合

### 用户角色

| 角色 | 职责 | 典型操作 |
|------|------|----------|
| 系统管理员 | 平台基础设施管理 | 学期配置、班级创建、教师管理、系统监控 |
| 教师 | 教学内容准备与评价 | 数据上传、课题配置、任务发布、作业批改 |
| 助教 | 协助教师批改作业 | 查看学生进度、批改作业、驳回重做 |
| 学生 | 实验操作与学习 | 问卷设计、样本量规划、抽样执行、报告撰写 |

### 系统架构

系统采用B/S架构，包含四个用户端：
- 学生端：线性向导式实验流程
- 教师端：课题管理与作业评价
- 助教端：协助批改作业（权限受限的教师端）
- 管理员端：系统基础设施管理

## 通用功能规范

### 一、登录与认证

#### 1.1 登录流程（所有角色通用）

**登录页面元素：**
- 账号输入框（学生用学号、教师用工号、助教用助教账号、管理员用管理员账号）
- 密码输入框
- 登录按钮
- 忘记密码提示文字

**【V3.0】完整登录流程：**

```
用户输入账号密码
    ↓
验证账号是否存在
    ↓ 不存在
    返回「账号或密码错误」（不透露账号是否存在）
    ↓ 存在
检查账号是否被锁定
    ↓ 已锁定
    返回「账号已被锁定，请X分钟后重试」
    ↓ 未锁定
验证密码是否正确
    ↓ 错误
    失败次数+1，若达到阈值则锁定账号
    返回「账号或密码错误，还剩X次尝试机会」
    ↓ 正确
清除失败计数
    ↓
检查账号状态是否正常（status=1）
    ↓ 已停用
    返回「账号已停用，请联系管理员」
    ↓ 正常
检查是否首次登录
    ↓ 是
    跳转到强制改密页面
    ↓ 否
记录登录日志
    ↓
生成会话令牌，跳转到首页
```

**【V3.0】登录失败锁定机制：**

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 最大失败次数 | 5次 | 连续失败次数阈值 |
| 锁定时长 | 30分钟 | 达到阈值后的锁定时间 |
| 计数重置 | 登录成功 | 成功登录后清除失败计数 |

**锁定状态显示：**
- 显示剩余锁定时间（如「请在28分钟后重试」）
- 锁定期间即使输入正确密码也不允许登录
- 管理员可手动解锁被锁定的账号

#### 1.2 首次登录强制改密

**触发条件：** 账号的「首次登录」标记为true

**页面元素：**
- 提示文字「首次登录，请设置新密码」
- 新密码输入框
- 确认密码输入框
- 实时密码强度指示器
- 确认按钮

**【V3.0】增强密码规则：**

| 规则 | 要求 | 实时反馈 |
|------|------|----------|
| 最小长度 | 8位以上 | ✓/✗ 至少8个字符 |
| 包含字母 | 至少1个字母 | ✓/✗ 包含字母 |
| 包含数字 | 至少1个数字 | ✓/✗ 包含数字 |
| 包含特殊字符 | 至少1个（!@#$%^&*等） | ✓/✗ 包含特殊字符 |
| 不含账号 | 不能包含账号字符串 | ✓/✗ 不包含账号信息 |
| 一致性 | 两次输入必须一致 | ✓/✗ 两次密码一致 |

**完成后：**
- 更新密码（加密存储）
- 将「首次登录」标记改为false
- 记录密码修改日志
- 跳转到对应角色首页

#### 1.3 【V3.0】会话管理

**会话超时：**

| 角色 | 超时时长 | 说明 |
|------|----------|------|
| 管理员 | 30分钟 | 安全敏感，较短超时 |
| 教师 | 2小时 | 批改作业需要较长时间 |
| 助教 | 2小时 | 同教师 |
| 学生 | 4小时 | 实验操作需要较长时间 |

**超时处理：**
- 超时前5分钟弹出提示「会话即将过期，是否继续？」
- 点击「继续」延长会话
- 超时后自动跳转到登录页，显示「会话已过期，请重新登录」
- 学生端：超时前自动保存当前实验进度

**【V3.0】单设备登录策略：**
- 同一账号同时只允许一个设备登录
- 新设备登录时，旧设备会话自动失效
- 旧设备下次操作时提示「您的账号已在其他设备登录」

#### 1.4 【V3.0】修改密码（非首次）

**入口：** 各角色端的个人设置或下拉菜单

**页面元素：**
- 当前密码输入框
- 新密码输入框
- 确认密码输入框
- 密码规则提示
- 确认按钮

**验证规则：**
- 当前密码必须正确
- 新密码必须符合密码规则
- 新密码不能与当前密码相同
- 【可选】新密码不能与最近3次使用的密码相同

**成功后：**
- 记录密码修改日志
- 可选：通知用户密码已修改（安全提醒）
- 不强制重新登录（保持当前会话）

#### 1.5 【V3.0】忘记密码处理

**处理方式：** 本系统采用管理员/教师重置的方式，不提供自助找回

**提示文字：**
- 学生：「忘记密码？请联系班级教师重置」
- 教师/助教：「忘记密码？请联系系统管理员重置」
- 管理员：需要通过服务器后台重置

**重置密码后：**
- 密码重置为账号（学号/工号/助教账号）
- 将「首次登录」标记设为true
- 下次登录强制修改密码

### 三、【V3.0】自动保存与草稿恢复

#### 3.1 自动保存

**适用场景：**
- 学生端：问卷设计、报告撰写
- 教师端：课题编辑、批改评语

**保存策略：**
- 每30秒自动保存一次
- 用户停止输入3秒后自动保存
- 页面底部显示「已自动保存于 HH:MM:SS」

**保存内容：**
- 存储到浏览器 localStorage（用于断网恢复）
- 同时发送到服务器（用于跨设备恢复）

#### 3.2 草稿恢复

**断网恢复：**
- 检测到网络断开时，提示「网络已断开，数据将保存在本地」
- 网络恢复后，自动同步本地数据到服务器
- 如有冲突，提示用户选择保留哪个版本

**跨设备恢复：**
- 登录后检测是否有未完成的草稿
- 如有草稿，弹窗提示「检测到未完成的内容，是否恢复？」
- 选项：「恢复草稿」「放弃草稿」

### 一、任务大厅

#### 1.1 页面布局

**主内容区：**

- 支持按状态筛选：全部/进行中/已提交/已批改

#### 1.2 任务卡片

**每张卡片显示：**
- 课题名称
- 课题背景描述（截取前80字，超出显示...）
- 发布时间
- 截止时间（如已设置）
- 剩余时间（如「还剩3天12小时」或「已截止」）

**状态标签及颜色：**

| 状态 | 颜色 | 含义 | 可执行操作 |
|------|------|------|------------|
| 未开始 | 灰色 | 学生尚未点击进入 | 开始实验 |
| 进行中 | 蓝色 | 已开始但未提交 | 继续实验 |
| 已提交 | 黄色 | 已提交，等待批改 | 查看提交内容 |
| 批改中 | 橙色 | 教师/助教正在批改 | 查看提交内容 |
| 已批改 | 绿色 | 已评分，可查看成绩 | 查看成绩 |
| 被驳回 | 红色 | 被驳回，需要重做 | 查看驳回理由、重新开始 |

**【V3.0】截止时间显示规则：**
- 剩余时间 > 7天：显示「还剩X天」
- 1天 < 剩余时间 ≤ 7天：显示「还剩X天X小时」（黄色警告）
- 剩余时间 ≤ 24小时：显示「还剩X小时X分钟」（红色警告）
- 已截止：显示「已截止」（灰色）

#### 1.3 【V3.0】截止时间边缘情况处理

**截止时间精度：** 精确到分钟

**截止判断规则：**
- 截止时间为 23:59 表示当天24:00前（含）可提交
- 系统时间 > 截止时间 时，禁止新的提交操作

**正在操作时截止的处理：**
- 学生正在实验过程中：可继续当前阶段，但无法进入下一阶段或提交
- 学生正在提交过程中：
  - 如果点击「提交」时已截止：提示「任务已截止，无法提交」
  - 如果点击「提交」时未截止，但服务器处理时截止：允许提交（宽限期30秒）

**截止后的可操作项：**
- 可查看已提交的内容
- 可查看成绩（如已批改）
- 不可重新提交（即使被驳回）
- 教师可延长截止时间后，学生恢复操作权限

#### 1.4 历史提交记录

**入口：** 任务卡片上的「历史记录」按钮

**显示内容：**
- 该课题下学生的所有提交记录列表
- 每条记录显示：
  - 提交时间
  - 状态（已批改/被驳回）
  - 得分（如有）
  - 批改人（如有）
- 点击可查看对应的问卷PDF和实验报告PDF
- 被驳回的记录显示驳回理由

### 三、阶段一：问卷设计

#### 3.1 整体结构

问卷设计采用向导式流程，分为四个步骤：
1. 欢迎语设置
2. 题目设计
3. 结束语设置
4. 预览确认

顶部显示步骤进度条，可点击已完成的步骤回退查看。

**【V3.0】自动保存：**
- 每个步骤的内容每30秒自动保存
- 底部显示「已自动保存于 HH:MM:SS」
- 离开页面前如有未保存内容，弹出确认提示

#### 3.2 步骤一：欢迎语设置

**页面元素：**
- 问卷标题输入框（必填，限制100字）
- 欢迎语富文本编辑器（必填，限制1000字）
- 字数统计显示
- 下一步按钮

**欢迎语用途提示：**
- 告知受访者调查目的
- 说明问卷大致用时
- 承诺数据保密等

#### 3.3 步骤二：题目设计

**页面布局：**
- 左侧：已添加的题目列表（可拖拽排序）
- 右侧：题目编辑区域
- 底部：推荐题目参考区域（可折叠）

**添加题目方式：**

**方式一：自建题目**
- 点击「添加题目」按钮
- 选择题目类型：判断题、单选题、多选题、满意度量表
- 填写题目内容

**方式二：引用推荐题目**
- 浏览教师设置的推荐题目列表
- 点击「使用」直接添加到问卷
- 添加后可修改题目内容

**各题型配置：**

| 题型 | 题目内容限制 | 选项配置 |
|------|--------------|----------|
| 判断题 | 1-500字 | 固定「是」「否」 |
| 单选题 | 1-500字 | 2-10个选项，每个1-200字 |
| 多选题 | 1-500字 | 2-10个选项，可设置选择数量限制 |
| 满意度量表 | 1-500字 | 固定1-10分，可设置两端标签 |

**题目列表操作：**
- 拖拽调整顺序
- 点击编辑
- 点击复制（【V3.0】新增）
- 点击删除（需确认）
- 显示题目序号（自动编号）

**【V3.0】题目数量验证：**
- 最少5题，最多50题
- 少于5题时，「下一步」按钮禁用，显示提示
- 达到50题后，「添加题目」按钮禁用

#### 3.4 步骤三：结束语设置

**页面元素：**
- 结束语富文本编辑器（必填，限制1000字）
- 字数统计显示
- 可包含致谢词、联系方式等

#### 3.5 步骤四：预览确认

**页面功能：**
- 模拟真实问卷的展示效果
- 显示完整问卷：欢迎语 → 所有题目 → 结束语
- 预览模式下题目可交互（用于测试体验）

**自动质量检测：**

| 检测项 | 规则 | 结果 |
|--------|------|------|
| 题目数量 | 5-50题 | 通过/不通过 |
| 题型多样性 | 至少2种不同题型 | 通过/警告 |
| 欢迎语 | 已填写且不少于20字 | 通过/不通过 |
| 结束语 | 已填写且不少于20字 | 通过/不通过 |
| 选项数量 | 单选/多选至少2个选项 | 通过/不通过 |

**检测结果展示：**
- 全部通过：显示「问卷结构完整」，可继续
- 有不通过项：显示具体问题，必须修复后才能继续
- 有警告项：显示警告，可选择继续或返回修改

**初步评分：** 给出问卷设计的机器评分（供参考，满分100）

**页面按钮：**
- 「返回修改」：回到题目设计步骤
- 「确认完成」：锁定问卷设计，进入下一阶段

**确认完成时的提示：**
```
确认后问卷设计将被锁定。

如需修改，您需要返回本阶段重新设计，届时后续阶段的数据将被清空。

确定继续吗？

[取消] [确认完成]
```

**底部按钮：**

#### 5.2 简单随机抽样

**说明文字：**
- 简要介绍简单随机抽样的原理
- 「从N个总体中随机抽取n个样本，每个个体被抽中的概率相等」

**操作区域：**
- 显示「将从 10,000 人中随机抽取 400 人」
- 「执行抽样」按钮
- 【V3.0】可选随机种子输入（用于复现结果）

**执行后：**

#### 5.3 系统抽样

**说明文字：**
- 简要介绍系统抽样的原理
- 「按固定间隔K从总体中抽取样本」

**参数输入区：**
- K值输入框
- 实时提示：
  - 建议K值（N/n）
  - 预计抽取数量
  - 如果K值不合理（导致样本过少或过多），显示警告

**【V3.0】K值验证：**
- K必须为正整数
- K不能大于N
- 预计样本数不能少于目标样本量的80%
- 预计样本数不能超过目标样本量的120%

**执行后：**
- 显示实际抽取的样本数量
- 显示样本数据预览
- 显示「重新抽样」按钮

#### 5.4 PPS抽样

**说明文字：**
- 简要介绍概率与规模成比例（PPS）抽样的原理

**参数输入区：**
- 选择规模变量（数值型字段）
- 指定抽样数量（允许在目标样本量的一定范围内调整）
- 可选随机种子

**执行后：**
- 显示抽样完成提示与样本数据预览
- 显示「重新抽样」按钮

#### 5.5 分层抽样

**说明文字：**
- 简要介绍分层抽样的原理

**步骤一：选择分层变量**

**步骤二：查看各层信息**

**步骤三：设定各层样本数**
- 快捷方式按钮：
  - 「比例分配」：按各层比例分配
  - 「等额分配」：每层分配相同数量
- 手动调整每层样本数
- 【V3.0】实时显示总数，必须等于目标样本量

**执行后：**
- 显示各层实际抽取数量
- 显示样本数据预览
- 显示「重新抽样」按钮

#### 5.6 完成本阶段

**条件：** 四种方法都至少执行过一次

**验证：**
- 四种方法都有有效的抽样结果
- 每种方法的样本数据已保存

### 四、课题管理

#### 4.1 课题列表页

**显示内容：**
- 表格展示当前教师创建的所有课题
- 列：课题名称、状态、数据行数、附件数、创建时间、操作

**状态筛选：** 全部/草稿/已发布

**操作按钮（按状态）：**
- 草稿状态：编辑、发布、删除
- 已发布状态：查看、编辑（受限）、【V3.0】复制、删除

#### 4.2 创建/编辑课题（6步向导）

**步骤一：基本信息**
- 课题名称（必填，1-200字）
- 背景描述（必填，富文本，1-10000字）

**步骤二：上传总体数据**
- 文件上传区域（xlsx/xls，最大50MB）
- 上传后显示：
  - 文件名
  - 数据行数
  - 数据列数
  - 数据预览（前20行）

**【V3.0】Excel验证规则：**
- 第一行必须是表头
- 表头不能有重复列名
- 数据行数：1-100,000行
- 数据列数：2-50列
- 不能有完全空白的行
- 数值列检测（用于后续字段映射）

**步骤三：字段映射**

选择并标记字段类型：

| 字段类型 | 说明 | 数量要求 |
|----------|------|----------|
| 标识符 | 用于标识个体，如ID | 必选1个 |
| 分层变量 | 用于分层抽样，如性别、地区 | 至少1个 |
| 数值变量 | 用于统计分析，如收入、年龄 | 至少1个 |
| 其他 | 不参与抽样分析 | 可选 |

**验证规则：**
- 至少选择3个字段
- 必须有1个标识符
- 至少有1个分层变量
- 至少有1个数值变量
- 分层变量的唯一值不超过20个

**步骤四：辅助资料**
- 附件上传区域
- 支持多文件上传
- 显示已上传文件列表
- 可删除已上传文件

**【V3.0】附件限制：**
- 单个文件最大：图片10MB，视频200MB，文档50MB
- 总附件数量最大：20个
- 支持格式：见全局限制规范

**步骤五：推荐题目**
- 添加推荐题目列表
- 每个推荐题目包含：题型、内容、选项配置
- 可拖拽排序
- 学生可在问卷设计时引用

**步骤六：评分权重**
- 问卷设计权重（10-50%）
- 实验过程权重（20-60%）

4. 如果教师A30分钟内无操作，锁自动释放
