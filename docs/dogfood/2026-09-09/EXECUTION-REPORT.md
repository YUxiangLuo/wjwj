## 5. 已确认的问题

### DF-001 / P2：CSV 额外空白行导致整表拒绝

复现：教师班级学生页→批量导入 `R1/downloads/student-import.csv`（文件末尾额外空行）。

实际：显示“导入失败: 表格行列结构不一致或引号未闭合”，有效行也没有导入。去掉空白行的 `student-import-no-blank.csv` 成功 2 条、失败 2 条，逐行错误正确。

影响：常见 CSV 导出/人工编辑空行需要额外清洗；错误提示没有指明空白行。未发现静默丢行或半批污染。

源码定位：`src/lib/spreadsheet.ts` 中 `parseUnquotedCsvText` 只移除一个末尾空字符串，其余空行因列数 1 与表头列数不同被标为 malformed。

建议：明确空行契约，统一 CSV/XLSX 行为；通常可跳过完全空白记录，但仍拒绝非空错列和未闭合引号，并保留正确的原始行号。待修复与回归。

### DF-002 / P2：创建班级默认选了非当前学期

前置：`DF-R1-2026秋季` 是当前学期，后创建的 `2025-2026学年第二学期` 非当前。

实际：重新打开“创建班级”，默认学期是后者，而不是当前学期；可手动修正。两次观察一致。

源码定位：`src/admin/pages/ClassManagement.tsx` 的 `loadInitialData` 默认 `semesters[0]?.id`，未优先 `isCurrent`。

建议：无已选值时优先当前学期；没有当前学期时明确要求选择或使用有说明的回退。待修复。

### DF-003 / P3：实验网络错误直接显示英文底层异常

复现：abort `/api/student/tasks/2/experiment`，刷新。

实际：显示 `Failed to fetch` 和“重试加载”，没有本地化的网络原因说明；恢复功能本身正常。

定位线索：`ExperimentLayout.tsx` 经 `requireApiData` / `useAsyncLoad` 将 API message 展示到 RequestError。建议针对 NETWORK_ERROR 做统一中文友好文案，保留诊断日志，不吞业务错误。
