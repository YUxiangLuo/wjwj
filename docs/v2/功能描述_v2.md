# 抽样统计虚拟仿真系统 - 功能详细描述 V2.0

## 文档说明

- **项目名称**：抽样统计虚拟仿真教学系统
- **版本**：V2.0
- **基于**：数据库设计 V2.0
- **文档目的**：详细描述系统各角色端的功能、页面结构、操作流程和业务规则

---

## 系统概述

### 核心理念

本系统旨在构建一个高度仿真的统计学抽样教学环境，通过「封闭式管理」架构，模拟真实的调研流程：从教师发布任务，到学生规划样本、实施抽样、分析误差，最终由教师进行多维度的评价。

核心设计原则：
- **Learning by Doing**：让学生在实践中理解理论，在对比中深化认知
- **过程导向**：关注学生的操作过程和决策逻辑，而非仅看结果
- **可视化对比**：通过图表直观展示不同抽样方法的效果差异
- **闭环反馈**：自动评分 + 人工点评相结合

### 用户角色

| 角色 | 职责 | 典型操作 |
|------|------|----------|
| 系统管理员 | 平台基础设施管理 | 学期配置、班级创建、教师管理、系统监控 |
| 教师 | 教学内容准备与评价 | 数据上传、课题配置、任务发布、作业批改 |
| 助教 | 协助教师批改作业 | 查看学生进度、批改作业、驳回重做 |
| 学生 | 实验操作与学习 | 问卷设计、样本量规划、抽样执行、报告撰写 |

### 系统架构

系统采用B/S架构，包含四个用户端：
- 学生端：线性向导式实验流程
- 教师端：课题管理与作业评价
- 助教端：协助批改作业（权限受限的教师端）
- 管理员端：系统基础设施管理

## 学生端详细功能描述

### 一、登录模块

#### 1.1 登录页面

**页面元素：**
- 学号输入框
- 密码输入框
- 登录按钮
- 忘记密码提示文字（提示联系教师或管理员重置）

**登录流程：**
1. 输入学号和密码，点击登录
2. 系统验证账号密码是否正确
3. 验证失败：提示「学号或密码错误」
4. 验证成功：
   - 检查账号状态是否正常（status=1）
   - 状态异常：提示「账号已停用，请联系管理员」
   - 状态正常：检查是否首次登录
5. **【V2.0】登录成功后，系统自动记录登录日志**

#### 1.2 首次登录强制改密

**触发条件：** 账号的「首次登录」标记为true

**页面元素：**
- 提示文字「首次登录，请修改密码」
- 新密码输入框
- 确认密码输入框
- 确认按钮

**密码规则：**
- 长度8位以上
- 必须包含字母和数字
- 两次输入必须一致

**完成后：**
- 更新密码
- 将「首次登录」标记改为false
- 跳转到任务大厅

### 二、任务大厅

#### 2.1 页面布局

**顶部导航栏：**
- 系统名称/Logo
- 当前用户姓名
- 退出登录按钮

**主内容区：**
- 任务卡片列表

#### 2.2 任务卡片

**每张卡片显示：**
- 课题名称
- 课题背景描述（截取前50字）
- 发布时间
- 截止时间（如已设置）
- 剩余时间（如「还剩3天」或「已截止」）
- 当前状态标签

**状态标签及含义：**

| 状态 | 含义 |
|------|------|
| 未开始 | 学生尚未点击进入 |
| 进行中 | 已开始但未提交 |
| 已提交 | 已提交，等待批改 |
| 已批改 | 教师已评分，可查看成绩 |
| 被驳回 | 教师驳回，需要重做 |

**卡片点击行为：**
- 未开始/进行中：进入实验流程
- 已提交：显示「等待批改中」提示，可查看已提交内容
- 已批改：进入成绩查看页面
- 被驳回：显示驳回理由，可选择重新开始

#### 2.3 历史提交记录入口

**位置：** 任务卡片上的「历史记录」按钮

**显示内容：**
- 该课题下学生的所有提交记录列表
- 每条记录显示：提交时间、状态（已批改/被驳回）、得分（如有）

- 被驳回的记录显示驳回理由

### 四、阶段一：问卷设计

#### 4.1 整体结构

问卷设计采用向导式流程，分为四个步骤：
1. 欢迎语设置
2. 题目设计
3. 结束语设置
4. 预览确认

顶部显示步骤进度条，可点击已完成的步骤回退查看，但修改需确认。

#### 4.2 步骤一：欢迎语设置

**页面元素：**
- 问卷标题输入框（必填，限制50字）
- 欢迎语富文本编辑器（必填，限制500字）
- 下一步按钮

**欢迎语用途提示：**
- 告知受访者调查目的
- 说明问卷大致用时
- 承诺数据保密等

#### 4.3 步骤二：题目设计

**页面布局：**
- 左侧：已添加的题目列表（可拖拽排序）
- 右侧：题目编辑区域
- 底部：推荐题目参考区域（可折叠）

**添加题目方式：**

**方式一：自建题目**
- 点击「添加题目」按钮
- 选择题目类型：判断题、单选题、多选题、满意度量表
- 填写题目内容

**方式二：引用推荐题目**
- 浏览教师设置的推荐题目列表
- 点击「使用」直接添加到问卷
- 添加后可修改题目内容

**各题目类型的配置：**

**判断题：**
- 题目内容（必填）
- 选项固定为「是」「否」

**单选题：**
- 题目内容（必填）
- 选项列表（至少2个，最多10个）
- 每个选项可编辑文字
- 可添加/删除选项

**多选题：**
- 题目内容（必填）
- 选项列表（至少2个，最多10个）
- 可设置最少选择数和最多选择数（可选）

**满意度量表：**
- 题目内容（必填）
- 量表范围固定为1-10
- 可设置两端标签（如「非常不满意」-「非常满意」）

**题目列表操作：**
- 拖拽调整顺序
- 点击编辑
- 点击删除（需确认）
- 显示题目序号（自动编号）

#### 4.4 步骤三：结束语设置

**页面元素：**
- 结束语富文本编辑器（必填，限制500字）
- 可包含致谢词、联系方式等

#### 4.5 步骤四：预览确认

**页面功能：**
- 模拟真实问卷的展示效果
- 显示完整问卷：欢迎语 → 所有题目 → 结束语
- 预览模式下不可编辑

**自动质量检测：**

检测规则：
- 题目数量是否在合理范围（如5-30题）
- 题目类型是否有多样性（不能全是同一种类型）
- 欢迎语和结束语是否已填写
- 单选/多选题的选项数量是否合理

检测结果展示：
- 通过：显示「问卷结构合理」
- 不通过：显示具体问题列表

初步评分：给出问卷设计的机器评分（供参考）

**页面按钮：**
- 「返回修改」：回到题目设计步骤
- 「确认完成」：锁定问卷设计，进入下一阶段

**确认完成时的提示：**
- 弹窗提示「确认后问卷设计将被锁定，如需修改需返回本阶段重新设计，届时后续阶段的数据将被清空。确定继续吗？」
- 用户确认后保存并进入阶段二

### 五、阶段二：样本量规划

#### 5.1 页面布局

**信息展示区：**
- 总体规模N（来自教师上传的Excel数据行数）
- 显示为「本次调查的总体规模为 N = 10,000 人」

**参数输入区：**

| 参数 | 输入方式 | 说明 |
|------|----------|------|
| 置信水平 | 下拉框 | 选项：90%、95%、99%，默认95% |
| 允许误差 | 输入框或滑块 | 范围1%-10%，默认5% |

**计算结果展示区：**
- 显示计算公式（教学目的）：`n = (Z² × p × (1-p)) / E²`
- 显示各参数含义
- 显示计算结果：「建议样本量 n = 384」

**最终决策区：**
- 提示文字「您可以根据实际情况调整最终样本量」
- 最终样本量输入框
- 输入范围限制（如最小30，最大不超过总体规模的50%）

#### 5.2 确认完成

点击「确认并进入下一阶段」按钮：
- 保存样本量规划数据
- 弹窗提示确认
- 进入阶段三

### 六、阶段三：抽样执行

#### 6.1 页面布局

**顶部信息：**
- 显示目标样本量n（来自阶段二）
- 显示总体规模N

**三种方法Tab或卡片：**
- 简单随机抽样
- 系统抽样
- 分层抽样
- 每种方法显示完成状态（已完成✓ / 未完成）

**底部按钮：**
- 「完成本阶段」：三种方法都完成后才可点击

#### 6.2 简单随机抽样

**说明文字：**
- 简要介绍简单随机抽样的原理
- 「从N个总体中随机抽取n个样本，每个个体被抽中的概率相等」

**操作区域：**
- 显示「将从 10,000 人中随机抽取 400 人」
- 「执行抽样」按钮

**执行后：**
- 显示抽样完成提示
- 显示样本数据预览（表格形式，显示前10条，可滚动查看更多）
- 显示「重新抽样」按钮

#### 6.3 系统抽样

**说明文字：**
- 简要介绍系统抽样的原理
- 「按固定间隔K从总体中抽取样本」

**参数输入区：**
- K值输入框
- 实时提示建议K值和预计抽取数量

**执行后：**
- 显示实际抽取的样本数量
- 显示样本数据预览
- 显示「重新抽样」按钮

#### 6.4 分层抽样

**说明文字：**
- 简要介绍分层抽样的原理

**步骤一：选择分层变量**
- 下拉框列出所有教师标记为「分层变量」的字段

**步骤二：查看各层信息**
- 表格展示各层人数和比例

**步骤三：设定各层样本数**
- 快捷方式按钮：「比例分配」「等额分配」
- 手动调整每层样本数

**执行后：**
- 显示各层实际抽取数量
- 显示样本数据预览
- 显示「重新抽样」按钮

#### 6.5 完成本阶段

**条件：** 三种方法都至少执行过一次

点击「完成本阶段」进入阶段四

### 附录C：三种抽样方法说明

**简单随机抽样 (Simple Random Sampling)**
- 原理：每个单位被抽中的概率相等
- 适用：总体同质性较高时

**系统抽样 (Systematic Sampling)**
- 原理：每隔K个单位抽取一个
- 计算：K = N / n

**分层抽样 (Stratified Sampling)**
- 原理：先分层，再从各层随机抽取
- 分配方式：比例分配、等额分配
