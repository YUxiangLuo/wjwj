# 教师端 Dogfood 计划（第三轮 · 新 seed 基线）

背景：第二轮 dogfood 之后产品有两批变化，本轮针对**变化后的真实教师端**重新设计场景：
- 移除账号停用/启用与管理员更换授课教师；班级归属创建后不可变更；
- 硬删除新增"影响面预览 + 显式确认"（`409 SUBMISSIONS_EXIST` / `?confirm=1`）；
- 导入改为按归属分类（本班已存在→跳过计数；他班→指名班级；其他教师→指向管理员），并支持错误明细下载；
- 管理员可删除无引用的教师；班级/学期/教师列表返回 `deleteBlockers`（学生调班能力已移除）；
- 演示 seed 重建为「2026 校园学习与生活状况调查」：5 模板 / 6 任务 / 17 实验 / 20 学生 / 4 班级（含空班、历史班、未开放任务、草稿、PPS 不可用、小总体）。

> 原则沿用：行为与终态优先，不做源码字符串/样式断言；每条场景给出证据与通过判据；发现缺陷即修复并补回归测试。

## 场景矩阵

### R1 教学概览与基线对账
1. T001 登录 → 概览「班级 2 / 模板 5 / 待批改 4 / 进行中任务 4」与 DB 逐项对账。
2. 进行中任务卡片：主任务 10 人、已完成 2、待批改 1、已驳回 1；比例任务 10/2/1/0；阅读任务 10/1/1/0；服务时段 6/2/1/1。
3. 判据：所有数字与 `experiment` 聚合一致（无软删除残留导致的口径漂移）。

### R2 模板生命周期（含新确认/守卫语义）
4. 模板列表 5 条（4 已发布 / 1 草稿）、总体行数合计 480。
5. 草稿「新生数字素养调查（设计阶段）」发布 → 被拒（缺总体数据），提示明确且不产生任务。
6. 复制主课题 → 副本可编辑（改名/描述），原件与其任务、学生快照不受影响。
7. 删除未分配副本 → 成功；删除已发布模板 → 被拒并给出原因（已分配/已发布）。
8. 五步向导开场：目标=均值、策略「简单必做/系统选做/PPS 不适用/分层选做」；阅读课题（N=24）显示小总体/普查提示；导入附件与推荐题可保存。
9. 判据：每次拒绝都发生在服务端且前端有可读提示，不出现"静默失败"或半写入。

### R3 学生名单、导入与删除（新语义）
10. 名单 10 人；页面无启停用入口；操作只有重置密码 / 删除。
11. 导入 A：全部新学号 → `successCount=N`。
12. 导入 B：本班已存在 → `skippedCount=N, failureCount=0`（不再报"学号已存在"为失败）。
13. 导入 C：跨教师学号 → 逐行提示「请先让对方教师从名单中删除该学生」；错误明细 CSV 可下载且含行号与原因。
14. 导入 D：非法邮箱/缺列/重复学号 → 逐行错误，且不产生半写入。
15. 删除无提交学生 → 一步删除；删除有提交学生 → 409 影响面 + `?confirm=1` 后成功，实验/成绩随之清除。
16. 重置密码 → 该生既有会话失效（重新登录失败），新密码=学号可登录。
17. 判据：导入与删除的计数、影响面数字与 DB 完全一致。

### R4 任务与截止（含未开放/已截止）
18. 发布到主班+副班：已存在班级跳过、返回 `skipped`。
19. 未开放任务（比例@副班）：学生端不可进入；教师任务列表状态正确（未开放）。
20. 已截止任务（主课题@历史班）：不属于 T001 列表（越权隔离），T003 侧可见为已截止。
21. 延期：早于当前截止或早于 now → 400；成功 +2 天并落库（UTC）。
22. 删除任务：有提交 → 影响面确认；无提交 → 一步删除。
23. 判据：三态（未开放/进行中/已截止）与入库时间一致，且截止后学生新写入被拒。

### R5 批改（加权、冲突、归档、快照）
24. 评分：`总分=Σ(问卷,过程,报告)×(30,30,40)%` 精确 2 位；写入批改人与时间。
25. 版本冲突：同一实验两窗口并发提交评分 → 一个成功、一个 `VERSION_CONFLICT`，冲突页保留输入且刷新后不丢。
26. 驳回：写 `rejectReason`、清分；学生修改重交后教师见 v2。
27. 归档只读：历史班成绩仅 T003 可见；T001 直接访问该实验 → 404。
28. 快照不可变：模板/学生改名后，已提交快照中的课题名与姓名不变。
29. 判据：成绩与 DB 一致，冲突不覆盖，越权不可读。

### R6 成绩分析与导出（内容级校验）
30. 漏斗/均值/已批改与 DB 对账（主任务、比例任务各一组）。
31. 按学期/班级/模板筛选结果正确；空结果不伪装成有数据。
32. 单任务与批量导出：下载 xlsx → 解析校验工作表名、表头顺序、行数、分数与 DB 一致。
33. 判据：导出内容级一致（不止 200/MIME）。

### R7 越权与归属不变量
34. 他人模板/任务/学生：读 403/404，写 403/404，且不产生副作用。
35. T002 看不到 T001 的班级与模板；T003 只看得到历史班。
36. 班级归属不可变更：不存在可改 `class.teacher_id` 的 API（管理端编辑仅改名）。
37. 判据：跨教师隔离在列表、详情、导出三层都成立。

### R8 对抗与恢复（补齐上轮未做项）
38. 网络失败（500/断网/超时）：提示错误并保留重试，不伪装空态；恢复后重试成功。
39. 脏输入：20 MiB 边界、xlsx 公式单元格、CSV 注入（`=cmd`）、超长名称、中文/emoji 文件名 → 明确拒绝或安全落库。
40. 键盘/焦点：弹窗关闭后焦点返回触发按钮；Tab 顺序可达到主要操作；sticky 操作条不遮挡内容。
41. 会话：跨角色 cookie 隔离、退出后回退、标签页切换账号 → 整页进入登录页而非半登录状态。
42. 判据：任何失败路径都有明确反馈，且不留下半写入或跨身份可用的会话。

- 结果记录：`test-results/teacher-dogfood-round3/REPORT-R3.md`（逐条 通过/缺陷/证据）。
