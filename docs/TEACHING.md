# 教学与账号指南

备课的数据、虚拟发放与统计边界见[课题模型](../RESEARCH_MODEL.md)。

## 五阶段多波次商业调研闭环

学生按顺序保存并推进五个阶段。已完成阶段可随时只读回看；重新编辑上游阶段需二次确认，并按依赖关系重置受影响的下游阶段与过期分析引用。

| 阶段 | 核心教学任务与完成条件 |
| --- | --- |
| 1. 商业问卷设计 | 围绕商业决策问题编辑问卷，将核心目标指标及分析变量绑定至课题数据字典（支持一键智能匹配绑定），完成受访者视角试填后保存 |
| 2. 首轮试投发放 | 制定 Wave 1 首轮试投样本量（支持先验经验标准差与参考经费测算），抽取至少一种试投名单并执行虚拟问卷发放与回收模拟 |
| 3. 回收质检与诊断 | 查看发放—触达—完答—有效样本转化漏斗，交互式切换剔除「闪电敷衍卷」与「直线作答卷」，诊断客群应答偏倚与逐题弃答/量程拦截，提交《抽样与投放调优决策单》 |
| 4. 调整思路与二轮投放 | 按需精简修订问卷，一键代入首轮实测无回答率与样本方差重算正式轮样本量，完成所有必做抽样方法（且至少完成两种启用方法）并执行正式轮问卷投放回收（含首轮试投在内单次实验最多支持 4 轮迭代） |
| 5. 商务分析与决策报告 | 复盘多轮改进记分卡与多口径教学误差带森林图，运行细分客群交叉对比或单变量分析并引用至附录，撰写 100–5000 字商业管理决策报告后预览提交 |

问卷、试投规划、调优决策单和报告草稿按实验版本保存在当前浏览器 7 天；抽样抽取、虚拟问卷发放、质检清洗规则与阶段完成均即时写入服务端并同步持久化至 `experiment_wave` 波次档案表。

## 变量字典、问卷绑定与客群交叉分析

- **教师模板配置**：在模板向导第 3 步配置研究合同（含「支撑的商业管理决策」）、字段角色并按需确认保存变量字典（启用问卷变量绑定与阶段五客群交叉/单变量分析时必配）；在第 4 步配置抽样方法要求及**虚拟问卷投放环境参数**（市场响应预设场景、基准无回答率、闪电/直线废卷率、单份触达与完答参考成本）。
- **问卷变量绑定**：核心研究目标字段在启用变量字典的课题中必须完成题目绑定，以确保虚拟发放后能采集主指标观测值；辅助指标未绑定时在有效回收答卷口径下记为未采集缺失。
- **细分客群交叉与单变量分析**：阶段五支持按任意名义/有序客群变量（如会员等级、城市线级、活跃分层）对连续或分类指标做交叉分组对比，并支持选择实验波次与数据集口径（质检清洗后有效答卷 vs 完整入样教学对照）。每个实验最多保存 20 条分析卡片，报告最多引用 10 条。
- **防篡改提交快照（`business-sampling-v3`）**：最终提交时，服务端对全部波次的抽样索引与虚拟问卷发放记录按保存种子逐一重放校验，冻结多波次诊断视图、调优决策单、目标估计、分析附录与变量字典，确保学生成绩页与教师批改台读取完全一致的证据链。

## 模板、任务与冻结

| 时点 | 冻结内容 |
| --- | --- |
| 模板发布后 | 总体数据、研究合同与字段映射、变量字典、抽样策略、虚拟发放配置、评分权重 |
| 首次分配后 | 另冻结名称、描述、推荐题和教学资料 |

需要修改冻结内容时可一键复制为新草稿模板继续编辑。

## 账号与不可逆删除

- 学号、工号分别全局唯一；学生仅属于一个班级。
- 学生、任务和未分配模板采用硬删除，级联清理关联实验、多波次记录、抽样审计与成绩；存在已提交或已批改实验时须显式确认。删除前请按 [DATABASE.md](../DATABASE.md) 完成配套备份。
- 密码与会话安全规则见 [SECURITY.md](../SECURITY.md)。
