# 教学与账号指南

备课的数据与统计边界见[课题模型](../RESEARCH_MODEL.md)。

## 四阶段

学生按顺序保存并推进。已完成阶段默认只读；重新编辑需确认，并会清理受影响的后续成果。

| 阶段 | 必要完成条件 |
| --- | --- |
| 1. 问卷预试 | 编辑并检查问卷，完成试填后保存；答案只用于认知预试，不进入估计或总体表 |
| 2. 样本量规划 | 设置精度、设计效应、回答率等参数，确认结果后保存 |
| 3. 抽样执行 | 完成所有必做方法，且实际完成至少两种启用方法；重抽替换该方法当前结果 |
| 4. 分析与报告 | 比较估计与设计指标、探索图表、撰写报告，预览后提交；教师评分或驳回重做 |

简单随机固定必做；系统与分层使用规划样本量，PPS 可在规划量的 80%–120% 内调整。必做 PPS 保存规划时会检查概率精度，不可用时须调整样本量或规模变量；失败不记为完成。具体统计口径及解释限制只在[课题模型](../RESEARCH_MODEL.md)维护。

问卷、规划和报告草稿按实验版本保存在当前浏览器 7 天，不是跨设备同步或服务端备份。同一实验在多个窗口编辑时，本机草稿采用最后一次实际编辑，不自动合并；阶段写入仍由服务端版本检查阻止旧页面覆盖新进度。学生端请求不自动重试：普通读取失败可手动重试，实验版本或数据来源变化时刷新页面后继续。抽样、阶段完成和提交即时写入服务端；服务端在写入前检查任务时间窗。

总体表和名册支持 `.xlsx` 或逗号分隔 CSV。无 BOM CSV 默认 UTF-8；GBK/GB18030 须在界面核对预览后转换，不能用切换编码修复已损坏文件。下载 CSV 使用 UTF-8 BOM 并防公式注入；编号前导零需在 Excel/WPS 中按文本导入。旧 `.xls` 必须另存为 `.xlsx`，不能只改扩展名。

## 可选的变量字典与自主分析

本节只说明当前已实现能力。XLSX 码本导出尚未实现，原有 CSV 导出不变。

- **教师字典**：在模板向导中确认字段标签、单位、连续/无序/有序类型、类别顺序及缺失编码。建议不会自动保存；数字外观不自动表示连续变量。超过 200 个类别的字段默认标为“不用于分析”，可明确改成连续数值。文本 `"01"`、`"1"`、数值 `1`、`false`、`0` 保持不同编码；缺失编码填写 JSON 标量数组。来源或修订冲突须重新载入核对。发布或分配后冻结，换源或改变字段解释须重新确认。
- **问卷关联**：数值题支持单位、含边界的上下限及小数位限制。关联只改变问卷草稿，随阶段一保存；服务器在保存及最终提交时检查任务、来源、字典修订和题意。改单词、规则或选项须重新关联；仅排序不影响关联，复制题目不继承关联。试填数据不参与分析。
- **单变量分析**：阶段四明确填写研究问题，选择实际完成的抽样结果、变量和口径，再点击执行。未加权描述使用有效值、样本标准差及 R7 分位数；设计加权只给出均值或类别比例的比率点估计，原始频数不冒充加权人数。加权分析要求总体目标字段无缺失，不提供加权分位数、标准误或置信区间，也不宣称无偏。
- **保存与引用**：成功分析自动保存不可变记录，同一请求重试不重复保存；每个实验最多 20 条，报告最多引用 10 条。单变量计算使用一个 Worker，最多排队 16 个任务，含排队在内限时 30 秒。配置修改不自动运行。引用随报告保存，附录不计入正文字数、不替代解释、不改变评分权重。
- **提交冻结**：提交时冻结所选结果、变量字典、题目关联及来源证据，师生读取同一份材料。重新编辑上游阶段会清空报告引用并使历史分析过期；相同种子重新抽样也产生新代次。仅重写正文不使分析失效。过期引用必须明确移除或重新运行，不能静默换成新结果。

以上能力均可选：没有字典、没有题目关联或不引用分析的实验仍可按原流程完成。

## 模板、任务与冻结

**实验模板**保存总体与教学配置；分配到班级后成为**实验任务**；**学生实验**保存个人进度。

| 时点 | 冻结内容 |
| --- | --- |
| 模板发布后 | 总体、研究目标与字段、变量字典、抽样策略、评分规则 |
| 首次分配后 | 另冻结名称、描述、推荐题和教学资料 |

需要修改冻结内容时复制为新模板。替换总体后必须重新配置研究目标与字段再发布。教师流程为：创建或复制模板 → 配置并发布 → 分配班级 → 批改或驳回。评分和驳回都需明确确认；未提交的评分不会自动保存。

## 账号与不可逆删除

- 学号、工号分别全局唯一；学生仅属于一个班级。系统不提供停用、无损转班或班级更换教师。
- 转班只能先由占用方删除，再由目标班导入；**历史实验和成绩不会保留**。
- 学生、任务和未分配模板采用硬删除。学生/任务删除会级联删除实验、成绩、抽样记录和相关审计明细；存在已提交或已批改实验时必须显式确认。删除不可恢复，应先按 [DATABASE.md](../DATABASE.md) 完成配套备份。
- 教师有班级或模板时不可删除；班级有学生或任务时不可删除；当前学期或有班级的学期不可删除。
- 学生和教师初始/重置密码分别为学号、工号；密码与会话安全规则见 [SECURITY.md](../SECURITY.md)。
