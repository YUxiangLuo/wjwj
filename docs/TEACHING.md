# 教学与账号指南

项目入口与启动见 [README](../README.md)，备课数据要求见[课题模型](../RESEARCH_MODEL.md)。本页只描述现行行为，不记录历史测试结果。

## 实验流程

学生按顺序完成四个阶段，通过底部主按钮保存到服务器并推进。已完成阶段默认只读；显式选择“重新编辑此阶段”并确认影响后才会重开，后续阶段的相关成果会被清理。

| 阶段 | 操作与完成条件 |
| --- | --- |
| 1. 问卷预试 | 编辑开场、题目、结束语；检查通过并完成试填后保存。支持三套可编辑骨架、教师推荐题及问卷规范 DOCX/PDF；选择答案后显式进入下一题，可按题号导航。预试答案不进入估计。 |
| 2. 样本量规划 | 明确目标、认识精度、了解影响因素、理解推荐、调整方案、检查与确认。猜测可跳过；各步「理解检查」解锁下一步；快速自检须答对每题后才能继续。试算不改动实际方案，最终一次保存规划。 |
| 3. 抽样执行 | 完成全部必做方法，且至少实际完成两种启用方法。参数先设置，结果落库后展示；演示可关闭，重抽替换当前方法结果。 |
| 4. 分析与报告 | 比较研究结果、探索图表、查看规划与抽样记录、撰写报告。保存后进入整份实验预览页，确认提交；教师可评分或驳回重做。 |

### 样本量与抽样口径

- 支持均值或比例规划：先以设计效应调整 Cochran `n₀`，再做有限总体校正 `n_fpc = n_deff × N / (N − 1 + n_deff)`，最后按预期回答率换算邀请数，以总体规模封顶。
- 反馈按所选邀请数和预期回答率显示实际可达精度，比例误差使用百分点。均值规划使用实际总体方差，读取失败可重试，不使用默认方差代替。
- 简单随机固定必做；系统与分层使用规划样本量；系统抽样允许分数间隔 `K=N/n`；PPS 可在规划样本量的 80%–120% 内调整。
- 必做 PPS 会在保存规划时验证当前样本量下至少一个辅助规模变量的概率精度。若被拦截，请调整样本量；普查可避开概率精度问题。抽样时遇到同类提示，可先换规模变量或使用规划样本量，再返回规划调整；不会将失败记为完成。
- PPS 为不放回 πps 抽样，使用 Hájek 加权均值；分层支持比例、等额、奈曼分配，奈曼需要层内标准差，超出层容量后回灌。
- 分析利用已知完整总体计算设计标准误，展示的是教学误差半宽。PPS 对全部随机起点区间进行精确积分，不配置蒙特卡洛次数；精度不足时显示不可用。Hájek 比估计仍可能有偏，精确设计标准误不保证正态区间覆盖率。

### 保存、冲突与时间窗

- 问卷、规划和报告草稿按实验版本保存在当前浏览器，退出后保留，最后编辑后保留 7 天；失败可重试。草稿不是跨设备同步或服务端备份。
- 检测到其他窗口更新草稿后，本页停止覆盖并阻止完成阶段；先复制保留本页内容，再重新进入加载最新草稿，不自动合并。
- 每次抽样即时落库；已完成阶段与提交使用服务端记录。切换报告工作区保留编辑内容和撤销记录，刷新恢复草稿及工作区。
- 服务端在接纳阶段保存、抽样、提交前检查任务时间窗。截止后新写入被拒，截止前已通过检查的请求允许完成；教师并发延长截止时间不会使其倒退。
- 每种方法页面预览前 50 行；PPS 另预览最多 10 行包含概率和权重，完整样本通过 CSV 导出。教师可看最近 100 次服务端抽样记录，更早记录在新抽样成功时清理。
- 学生成绩页只显示总分、评分权重和教师评语，不公开分项具体分数。

## 教师配置与冻结

**实验模板**保存总体数据与教学配置；**实验任务**是模板分配到一个班级后的实例；**学生实验**保存个人进度和提交。

| 时点 | 冻结内容 |
| --- | --- |
| 模板发布后 | 总体数据、研究目标与字段、抽样策略、评分规则 |
| 分配给任一班级后 | 名称、描述、推荐题和教学资料也转为只读 |

需要调整时复制为新模板再发布。替换总体文件后须重新配置研究目标与字段，再发布；字段角色或估计目标实际变更时重新判定抽样策略，未变更配置或仅修改文字说明不会覆盖已有有效策略。教师首页展示活动任务；成绩分析支持进度漏斗、总分分布、均值/中位数、三项平均分与导出。

## 账号与删除

- 学号、工号分别全局唯一，学生只属于一个班级。没有账号启用/停用、学生转班或班级更换教师功能。
- 导入本班已有学号会跳过且不改名改密；同教师其他班占用时提示班级，跨教师占用不泄露班级名。并发冲突逐行分类，错误明细可下载 CSV。
- 换班只能由占用方先删除，再由目标班级重新导入，**历史实验和成绩不会保留**；不能把它当作无损转班。
- 学生、任务、未分配模板使用硬删除；学生/任务删除会清除关联实验、成绩、抽样记录及相关审计明细。有已提交或已批改实验时，服务端要求显式确认。删除动作另保留脱敏审计。
- 教师有班级或模板时不可删除；班级有学生或任务时不可删除；当前学期或有班级的学期不可删除。
