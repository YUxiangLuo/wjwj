# 教学与账号指南

项目入口与启动见 [README](../README.md)，备课数据要求见[课题模型](../RESEARCH_MODEL.md)。本页只描述现行行为，不记录历史测试结果。

## 实验流程

学生按顺序完成四个阶段，通过底部主按钮保存到服务器并推进。已完成阶段默认只读；显式选择“重新编辑此阶段”并确认影响后才会重开，后续阶段的相关成果会被清理。

| 阶段 | 操作与完成条件 |
| --- | --- |
| 1. 问卷预试 | 编辑开场、题目、结束语；检查通过并完成试填后保存。支持三套可编辑骨架、教师推荐题及问卷规范 DOCX/PDF；是/否、单选、评分题首次选择后自动继续；多选在选项下方确认；数值题输入有效数值后明确继续，输入时不自动跳转，支持 Enter 继续。返回已答题可修改且不自动跳转，支持题号导航；结束语仍需明确完成试填。预试答案不进入估计。 |
| 2. 样本量规划 | 进入即调整参数，双栏实时对照设置与结果，无需答题。底部固定确认/保存操作；「计算依据与原理」可按需查看，示例试算不改动实际方案。草稿只记录当前页面和参数，不再解释旧答题页或启动页；确认后一次保存并直接进入抽样。 |
| 3. 抽样执行 | 完成全部必做方法，且至少实际完成两种启用方法。参数先设置，结果落库后展示；演示可关闭，重抽替换当前方法结果。 |
| 4. 分析与报告 | 比较研究结果、探索图表、查看规划与抽样记录、撰写报告。保存后进入整份实验预览页，确认提交；教师可评分或驳回重做。 |

切换抽样方法或报告工作区时，页面自动定位到对应操作区，键盘焦点回到当前标签。尚未执行的分层配置在切换方法时保留；执行成功后，参数才随结果写入服务器。长报告在编辑框内滚动，字数和长度要求始终显示在底部保存按钮旁，不必滚到正文末尾检查。

单选、多选的编辑保存、阶段保存、检查试填和最终提交统一拒绝重复选项，不再放行已完成阶段中的旧重复项；需要重开问卷阶段修正后重新完成后续流程。比较时忽略首尾空白、合并连续空白并统一全半角 ASCII 字母、数字和标点，但保留 `X`/`x` 的大小写以及 `10²`/`102` 等数学含义差异。选项必须为非空文本，多选数量和评分范围必须为整数，不自动丢弃空选项、转换类型或取整。题目身份必须唯一；题目或选项变更后不沿用旧试填作答。已提交的历史快照和成绩不因此改写。

推荐题目读取只接受原生 JSON 数组，整组严格校验；缺失身份、重复身份、未知题型或损坏条目会明确报错，不跳过题目、不自动生成身份、不解包 JSON 字符串。使用骨架、推荐题或复制创建新题目时，才生成新题目/选项身份。已应用的高级样本量方案必须有可复核快照，无论何时保存的记录都不例外。

问卷试填是认知预试，不会为总体表生成新变量或每个样本的答案。题目可显式关联教师确认字典中的已有变量，这只表示含义对应，不表示既有数据由本问卷采集。样本导出保留总体表的全部原始字段；问卷中自行增加、但总体表不存在的变量不会凭空出现在样本数据中。阶段 4 提供自动研究结果和图表探索，尚不提供独立的回归建模流程。

### 表格编码与中文 Excel/WPS

- 选择总体表或学生名册 CSV 后，先在本地确认编码与内容，不立即上传或写入账号。支持 UTF-8、GBK/GB18030、UTF-16 LE/BE 的逗号分隔文件；有 BOM 时锁定其声明的编码，无 BOM 时默认尝试 UTF-8，失败不会自动切换。
- 无 BOM 文件可能合法于多种编码，请对照原文件核对预览中的中文、编号和列名，需要时手动选择 GBK/GB18030。原文件若为 UTF-8 且已损坏，应重新导出，不能靠切换编码“修复”。确认后完整内容转为 UTF-8 + BOM，转换后的文件也不得超过 20 MiB；样本和后续模板读取沿用这一确定的解释。预览仅显示前 20 行，长文本显示会截断但保存内容不会截断。
- 新上传接口接受严格 UTF-8 或带 BOM 的 UTF-16，不会静默回退其他编码；GBK 应通过界面选择编码、确认并转换后上传，或从原文件另存为“CSV UTF-8（逗号分隔）”/`.xlsx`。存储读取采用同一严格解码规则，不再将 UTF-8 解码失败自动解释为 GBK/GB18030。原先以 GBK 保存的文件需核对后转换并重新上传，不会自动改写源文件。制表符分隔的“Unicode 文本”不等于逗号分隔 CSV。
- 学生和教师的样本 CSV 下载使用 **UTF-8 + BOM**，帮助 Windows Excel/WPS 识别中文，并保留公式注入防护。CSV 不保存单元格格式；需要保留编号前导零时，应通过导入向导将编号列设为文本。
- `.xlsx` 按工作簿格式解析，不套用 CSV 的字符编码。旧 `.xls` 请另存为 `.xlsx`，不要仅修改扩展名。

### 样本量与抽样口径

- 支持均值或比例规划：先以设计效应调整 Cochran `n₀`，再做有限总体校正 `n_fpc = n_deff × N / (N − 1 + n_deff)`，最后按预期回答率换算邀请数，以总体规模封顶。
- 反馈按所选邀请数和预期回答率显示实际可达精度，比例误差使用百分点。均值规划使用实际总体方差，读取失败可重试，不使用默认方差代替。
- 简单随机固定必做；系统与分层使用规划样本量；系统抽样允许分数间隔 `K=N/n`；PPS 可在规划样本量的 80%–120% 内调整。
- 必做 PPS 会在保存规划时验证当前样本量下至少一个辅助规模变量的概率精度。若被拦截，请调整样本量；普查可避开概率精度问题。抽样时遇到同类提示，可先换规模变量或使用规划样本量，再返回规划调整；不会将失败记为完成。
- PPS 为不放回 πps 抽样，使用 Hájek 加权均值；分层支持比例、等额、奈曼分配，奈曼需要层内标准差，超出层容量后回灌。
- 分析利用已知完整总体计算设计标准误，展示的是教学误差半宽。PPS 对全部随机起点区间进行精确积分，不配置蒙特卡洛次数；精度不足时显示不可用。Hájek 比估计仍可能有偏，精确设计标准误不保证正态区间覆盖率。

### 保存、冲突与时间窗

- 问卷、规划和报告草稿按实验版本保存在当前浏览器，退出后保留，最后编辑后保留 7 天；失败可重试。草稿不是跨设备同步或服务端备份。
- 检测到其他窗口更新草稿后，本页停止覆盖并阻止完成阶段；先复制保留本页内容，再重新进入加载最新草稿，不自动合并。
- 每次抽样即时落库；已完成阶段与提交使用服务端记录。切换报告工作区保留编辑内容和撤销记录，刷新恢复草稿及工作区。
- 服务端在接纳阶段保存、抽样、提交前检查任务时间窗。截止后新写入被拒，截止前已通过检查的请求允许完成；教师并发延长截止时间不会使其倒退。
- 每种方法页面预览前 50 行；PPS 另预览最多 10 行包含概率和权重，完整样本通过 CSV 导出。教师可看最近 100 次服务端抽样记录，更早记录在新抽样成功时清理。
- 学生成绩页只显示总分、评分权重和教师评语，不公开分项具体分数。

## 教师配置与冻结

**实验模板**保存总体数据与教学配置；**实验任务**是模板分配到一个班级后的实例；**学生实验**保存个人进度和提交。

| 时点 | 冻结内容 |
| --- | --- |
| 模板发布后 | 总体数据、研究目标与字段、变量字典、抽样策略、评分规则 |
| 分配给任一班级后 | 名称、描述、推荐题和教学资料也转为只读 |

需要调整时复制为新模板再发布。替换总体文件后须重新配置研究目标与字段，再发布；字段角色或估计目标实际变更时重新判定抽样策略，未变更配置或仅修改文字说明不会覆盖已有有效策略。教师首页展示活动任务；成绩分析支持进度漏斗、总分分布、均值/中位数、三项平均分与导出。

### 变量字典

在模板向导第 3 步“研究目标与字段”，点击 **保存字段并配置字典**：先明确保存本页字段配置，再打开独立字典编辑器，不推进步骤。保存字段失败时不会打开旧字典。该配置当前可选，不增加学生完成条件。

- 初次打开显示建议，不自动确认；在左侧选择或查找变量，编辑显示名称、单位、测量类型和分析读取方式。源字段名及标识符用途不能在字典中修改。
- 无序/有序分类需列出全部真实类别原值与标签；有序类别按从上到下排序。可将类别设为缺失，或额外声明缺失编码。文本“01”、文本“1”和数值 `1` 是不同编码；空单元格自动视为缺失，`0`/`false` 不自动视为缺失。
- 改变读取方式不会自动转换已有编码；数值读取使用 XLSX 原始值。服务器校验完整总体，不以少量预览代替完整类别覆盖。
- 点击 **确认并保存字典** 才写入。字典草稿仅保留在当前弹窗内；关闭或重新加载前有放弃修改确认，刷新不恢复草稿。保存失败保留输入；版本/来源冲突必须重新加载并核对，不自动合并或覆盖。
- 模板详情的“字段映射”页可只读查看字典；已发布或已分配任务的模板须复制后修改。替换总体文件或改变字段用途会使原字典失效；等价配置保存保留已确认字典。历史任务不自动补字典。

当前字典与题目关联用于明确数据含义；自主分析记录、回归和结果引用尚未接入。

### 学生题目与变量关联（可选）

- 在“设计题目”的题目卡片点击 **关联已有变量**。只读取本班已开放任务的已确认字典；教师未确认字典时，保持“仅认知预试，不关联数据”即可，不增加完成门槛。
- 单选、是/否题需与同一个分类变量的全部有效类别一一对应，原值类型精确匹配。评分题只可按已声明的有序类别逐级对应，不能把任意连续金额、时长强行当作评分选项。数值题独立填写实际数值，不使用评分选项。
- 数值题明确配置单位、上下限（含边界，留空不限制）和最多小数位（0 为整数，留空不限制）。严格接受可可靠表示的十进制/科学计数法，不把空值当 0、不自动舍入、不接受带前导零的编码或千位分隔符；末尾零不改变数值。单位留空表示未声明，不自动推断。
- 数值题可直接关联已确认的连续数值变量，单位须与字典完全一致，不做单位换算；两侧均未声明单位时仍需自行核对。范围和小数位仅约束认知试填，不声称完整总体已满足这些限制，也不筛选、截断或修改原始数据。此关联只有变量引用，不生成选项编码、虚构答案列或新的采集记录。
- 多选的每个选项必须选择不同的真实二值字段，并明确选中时的原值；另一有效编码表示未选中，缺失仍为缺失。不能把一列普通分类变量冒充多个响应列。
- 点击 **确认关联到问卷草稿** 只修改草稿；仍需完成明确结束的试填，并通过原阶段保存按钮提交。修改题干、选项或规则会清除原关联并提示重新核对；复制题目不继承关联，单纯调整题目顺序保留关联。
- 关联记录包含任务、数据来源、字典修订和题目语义快照；选项题记录独立选项身份与原值，数值题直接记录连续变量引用。阶段保存和最终提交均校验；版本/来源改变不能自动合并或重设版本。
- 批改材料和学生提交详情使用提交时的字典显示精确源字段与编码，不把当前模板定义追加到旧提交。打开关联编辑器不补造选项身份；缺少身份时须先明确编辑保存题目，再确认关联。无关联题目仍为认知预试，不自动建立关联。

### 教师操作

- 自建实验入口：**实验模板 → 创建实验模板（上传 CSV/XLSX）或复制可访问的模板 → 配置并发布 → 实验任务 → 分配班级**。任务选择器只列出已发布模板，不代表只能使用系统预置任务；统计目标仍限于现行均值/比例模型。
- 模板向导的流程说明可按需展开；换步后回到本步开头。保存、上传期间显示进度并阻止重复提交、切步和关闭；失败后保留本页输入供重试。复制模板后自动显示草稿并定位副本的编辑入口。
- 批改时左侧阅读材料，材料标签与右侧的学生身份、评分和评语保持可见；切换材料不清空输入。评分与驳回需明确确认，处理中不能重复操作或修改输入，失败后可重试。未提交的评分不自动保存到服务器。
- 批改列表的状态、已应用搜索和页码保留在网址中；查看详情、评分或驳回后返回同一筛选。原末页变空时自动回到有效页；翻页不会悄悄应用尚未点击搜索的文字。

## 账号与删除

- 学号、工号分别全局唯一，学生只属于一个班级。没有账号启用/停用、学生转班或班级更换教师功能。
- 导入本班已有学号会跳过且不改名改密；同教师其他班占用时提示班级，跨教师占用不泄露班级名。并发冲突逐行分类，错误明细可下载 CSV。
- 换班只能由占用方先删除，再由目标班级重新导入，**历史实验和成绩不会保留**；不能把它当作无损转班。
- 学生、任务、未分配模板使用硬删除；学生/任务删除会清除关联实验、成绩、抽样记录及相关审计明细。有已提交或已批改实验时，服务端要求显式确认。删除动作另保留脱敏审计。
- 教师有班级或模板时不可删除；班级有学生或任务时不可删除；当前学期或有班级的学期不可删除。
