# Admin 端端到端（E2E）测试清单

本文档详细列出管理员端前端应覆盖的端到端测试用例，基于 `docs/v3/功能描述_v3.md` 规范及当前代码实现。

> **约定**
>
> - 每条用例标注关键 `data-testid` 选择器，方便自动化测试定位元素。
> - 「前置条件」说明测试前必须满足的数据/状态。
> - 「验证点」列出需要断言的结果。

## 1. 登录与认证

### 1.1 正常登录

| 编号 | 用例 | 操作 | 验证点 |
|------|------|------|--------|
| AUTH-001 | 正确账号密码登录 | 在 `[data-testid="admin-login-username"]` 输入管理员账号，`[data-testid="admin-login-password"]` 输入密码，点击 `[data-testid="admin-login-submit"]` | 跳转到首页仪表盘；页面显示管理员用户名 |
| AUTH-002 | 已登录状态访问登录页 | 已登录后直接访问 `/login` | 自动重定向到首页 `/` |
| AUTH-003 | 登录按钮 loading 状态 | 点击登录后、响应返回前 | 按钮显示加载动画，按钮不可重复点击 |

### 1.2 登录失败

| 编号 | 用例 | 操作 | 验证点 |
|------|------|------|--------|
| AUTH-004 | 空用户名或空密码提交 | 不填写用户名或密码，点击登录 | 表单提交被阻止或显示验证提示 |
| AUTH-005 | 错误密码登录 | 输入正确用户名 + 错误密码 | 显示红色错误提示信息 |
| AUTH-006 | 不存在的账号登录 | 输入不存在的用户名 | 显示错误提示信息 |
| AUTH-007 | 连续5次失败锁定账号 | 连续5次输入错误密码 | 第6次登录提示账号已被锁定，显示剩余锁定时间（默认30分钟） |
| AUTH-008 | 锁定期间尝试登录 | 在锁定期间使用正确密码登录 | 仍然提示锁定，无法登录 |

### 1.3 首次登录强制改密

| 编号 | 用例 | 操作 | 验证点 |
|------|------|------|--------|
| AUTH-009 | 首次登录弹出改密弹窗 | 使用首次登录账号（`isFirstLogin=1`）登录 | 登录成功后弹出强制修改密码弹窗，无法关闭 |
| AUTH-010 | 密码规则校验 — 长度不足 | 输入少于8位的新密码 | 显示长度不足提示 |
| AUTH-011 | 密码规则校验 — 缺少特殊字符 | 输入仅含字母和数字的密码 | 显示需要特殊字符提示 |
| AUTH-012 | 密码规则校验 — 包含用户名 | 输入包含管理员用户名的密码 | 显示不能包含用户名提示 |
| AUTH-013 | 新密码与确认密码不一致 | 两次输入不同密码 | 显示密码不匹配提示 |
| AUTH-014 | 首次改密成功 | 输入符合规则的新密码并确认 | 弹窗关闭，正常进入系统 |

### 1.4 修改密码（非首次）

| 编号 | 用例 | 操作 | 验证点 |
|------|------|------|--------|
| AUTH-015 | 在系统设置页修改密码 | 打开系统设置 → 输入当前密码 + 新密码 + 确认密码 | 修改成功提示，当前会话保持 |
| AUTH-016 | 当前密码错误 | 输入错误的当前密码 | 显示当前密码不正确提示 |
| AUTH-017 | 管理员密码至少12位 | 输入不足12位的新密码 | 显示密码长度不足提示 |

### 1.5 登出

| 编号 | 用例 | 操作 | 验证点 |
|------|------|------|--------|
| AUTH-018 | 正常登出 | 点击 `[data-testid="admin-logout-trigger"]` | 跳转到登录页，Session Cookie 被清除 |
| AUTH-019 | 登出后无法访问管理页面 | 登出后直接访问 `/` | 重定向到 `/login` |
