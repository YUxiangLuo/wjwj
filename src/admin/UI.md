## 三、学期管理

### 3.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│ 学期列表                                    [+ 创建学期]    │
├─────────────────────────────────────────────────────────────┤
│ 学期名称    │ 状态      │ 班级数量 │ 创建时间   │ 操作      │
├─────────────────────────────────────────────────────────────┤
│ 2024-Spring │ 当前学期  │ 8        │ 2024-02-01 │ [删除]    │
│ 2023-Fall   │ 历史学期  │ 6        │ 2023-09-01 │ [设为当前] [删除] │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 学期ID |
| name | string | 学期名称，格式：YYYY-Spring 或 YYYY-Fall |
| is_current | boolean | 是否为当前学期 |
| class_count | number | 关联班级数量（聚合查询） |
| created_at | datetime | 创建时间 |

### 3.3 操作说明

| 操作 | 条件 | 确认弹窗 |
|------|------|----------|
| 创建学期 | 名称不重复 | 无 |
| 设为当前 | 非当前学期 | 无（直接切换） |
| 删除 | class_count = 0 | "确定删除学期「{name}」吗？" |

### 3.4 创建学期弹窗

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 学期名称 | Input | ✓ | 格式：YYYY-Spring 或 YYYY-Fall |
| 设为当前学期 | Switch | - | 勾选后自动取消其他学期的当前状态 |

### 3.5 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/semesters` | 获取学期列表 |
| POST | `/api/admin/semesters` | 创建学期 |
| PUT | `/api/admin/semesters/:id/current` | 设为当前学期 |
| DELETE | `/api/admin/semesters/:id` | 删除学期 |

## 四、教师管理

### 4.1 页面结构

```
┌─────────────────────────────────────────────────────────────────────┐
│ 教师列表                           [搜索框]        [+ 添加教师]     │
├─────────────────────────────────────────────────────────────────────┤
│ 工号  │ 姓名 │ 状态   │ 班级数 │ 最后登录      │ 创建时间   │ 操作  │
├─────────────────────────────────────────────────────────────────────┤
│ T001  │ 张三 │ 正常   │ 3      │ 2024-03-15... │ 2023-09-01 │ ...   │
│ T002  │ 李四 │ 正常   │ 2      │ 2024-03-14... │ 2023-09-01 │ ...   │
│ T003  │ 王五 │ 已停用 │ 0      │ 2024-01-10... │ 2023-09-15 │ ...   │
│ T004  │ 赵六 │ 已锁定 │ 3      │ -             │ 2024-01-01 │ ...   │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 教师ID |
| employee_id | string | 工号 |
| name | string | 姓名 |
| status | number | 状态：1=正常, 0=停用 |
| is_locked | boolean | 是否被锁定（登录失败5次） |
| lock_until | datetime | 锁定解除时间 |
| class_count | number | 关联班级数（聚合查询） |
| last_login | datetime | 最后登录时间（从 login_log 获取） |
| created_at | datetime | 创建时间 |

### 4.3 状态显示

| 状态 | Badge样式 | 说明 |
|------|-----------|------|
| 正常 | bg-emerald-100 text-emerald-700 | status=1 且未锁定 |
| 已停用 | variant="destructive" | status=0 |
| 已锁定 | bg-orange-100 text-orange-700 | is_locked=true |

### 4.4 操作按钮

| 操作 | 条件 | 确认弹窗 |
|------|------|----------|
| 重置密码 | 始终可用 | "确定重置教师「{name}」的密码吗？密码将重置为工号，下次登录需要修改密码。" |
| 停用 | status=1 | 见功能描述文档 4.3 节 |
| 启用 | status=0 | "确定启用教师「{name}」吗？" |
| 解锁 | is_locked=true | "确定解锁教师「{name}」吗？" |

### 4.5 添加教师弹窗

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 工号 | Input | ✓ | 1-50字符，唯一性验证 |
| 姓名 | Input | ✓ | 1-100字符 |

提示文字：「初始密码为工号」

### 4.6 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/teachers` | 获取教师列表，支持 ?search= 搜索 |
| POST | `/api/admin/teachers` | 添加教师 |
| PUT | `/api/admin/teachers/:id` | 编辑教师（姓名） |
| PUT | `/api/admin/teachers/:id/status` | 停用/启用 |
| PUT | `/api/admin/teachers/:id/unlock` | 解锁账号 |
| POST | `/api/admin/teachers/:id/reset-password` | 重置密码 |

## 十二、API 通用规范

### 12.1 响应格式

```typescript
// 成功响应
{
  success: true,
  data: T
}

// 错误响应
{
  success: false,
  error: {
    code: string,    // 如 "AUTH_001"
    message: string  // 用户可读的错误信息
  }
}
```

### 12.2 列表接口

```typescript
// 请求参数
{
  page?: number,      // 默认 1
  pageSize?: number,  // 默认 20
  search?: string,    // 搜索关键词
  // ...其他筛选参数
}

// 响应数据
{
  items: T[],
  total: number,
  page: number,
  pageSize: number
}
```

### 12.3 认证

- 使用 Cookie 存储 session token
- 所有 `/api/admin/*` 接口需要管理员身份验证
- 未认证返回 401，权限不足返回 403
